# 文风分析模板

## 概述

本模板用于分析参考小说的文风特点，生成文风总结文档供AI写作时参考。

**输出位置**：`plan/02-核心设定/参考作品与文风.md`

---

## 分析维度

### 1. 句式结构

#### 句长分布
- 平均句长：__ 字
- 最短句：__ 字
- 最长句：__ 字
- 长短句比例：__:__

**统计方法**：随机抽取1000句话，计算字数分布

#### 句型偏好
- [ ] 陈述句为主
- [ ] 疑问句较多（设悬念）
- [ ] 感叹句点缀（情感高潮）
- [ ] 排比句（气势渲染）

**示例**：
```
原文：他看着手中的长剑，心中涌起一股热血。
分析：陈述句 + 心理描写，18字，中等长度
```

### 2. 对话风格

#### 对话占比
- 对话占总字数比例：__%

#### 对话特点
- [ ] 口语化强（如："咋整"、"牛逼"）
- [ ] 文言味浓（如："何故"、"岂能"）
- [ ] 半文半白（网文常见）
- [ ] 现代白话（都市类）

#### 标点使用
- 感叹号频率：高/中/低
- 省略号使用：多/少
- 破折号用途：解释/转折/声音延长

**示例**：
```
原文："你小子，还真敢来啊！"张长老冷笑道。
分析：
- 口语化表达："你小子"、"还真"
- 情绪词："冷笑"
- 标点：感叹号表强烈语气
```

### 3. 描写密度

#### 动作描写
- 占比：__%
- 特点：
  - [ ] 细致分解（一动作一步）
  - [ ] 概括性描写（一笔带过）
  - [ ] 武招名称多（修仙类）

#### 环境描写
- 占比：__%
- 触发时机：
  - [ ] 场景转换时必写
  - [ ] 仅重要场景详写
  - [ ] 几乎不写（快节奏）

#### 心理描写
- 占比：__%
- 方式：
  - [ ] 直接叙述（"他想..."）
  - [ ] 行为暗示（通过动作表现心理）
  - [ ] 内心独白（独立段落）

**示例**：
```
原文：秦墨握紧拳头，指节发白。他深吸一口气，眼神逐渐坚定。
分析：
- 动作描写：握紧拳头、深吸气（间接表现心理）
- 神态描写：指节发白、眼神坚定（外化内心）
- 无直接"他想..."（避免AI味）
```

#### AI味检测清单

以下表达应**避免**或在后处理中替换：

| AI味表达 | 替换方案 |
|---------|---------|
| 从此以后... | 删除或用具体事件暗示 |
| 让我们... | 改为直接行动 |
| 他心中暗想... | 改为行为描写 |

## 使用方法

### 方法A：用户提供文本文件

```bash
# 用户将参考小说文本放入项目目录
# 例如：《参考小说》.txt

# Skill自动分析并生成文风报告
python analyze_style.py --input "《参考小说》.txt" --output "plan/02-核心设定/参考作品与文风.md"
```

### 方法B：用户指定已知作家

```
用户：参考猫腻的风格
Skill：基于已有知识生成猫腻文风分析
      （重点：句式优雅、对话机智、情感细腻）
```

### 方法C：无参考（使用默认风格）

```
用户：没有参考，就用通用网文风格
Skill：使用预设的"标准网文风格"配置
      （详见本文档默认值）
```

## 默认风格配置（无参考时使用）

当用户不提供参考作品时，使用以下默认配置：

```yaml
sentence:
  avg_length: 20        # 平均句长20字
  pattern: mixed         # 长短句混合
  ratio: "4:3:3"        # 中:短:长
  
dialogue:
  percentage: 30%        # 对话占30%
  style: colloquial      # 半口语化
  punctuation: moderate  # 适度使用感叹号
  
description:
  action: detailed       # 动作细致分解
  environment: minimal   # 环境简写
  psychology: indirect   # 心理间接描写
  
pacing:
  paragraph_length: 5    # 平均5行一段
  rhythm: alternating    # 快慢交替
  chapter_end: suspense  # 悬念结尾
  
vocabulary:
  anti_ai_list:          # 禁用词汇表
    - "从此以后"
    - "让我们"
    - "他心中暗想"
    - "不禁"
    - "在这个世界上"
    
emotion:
  tone: passionate       # 热血激昂
  transitions:           # 情感转换
    - calm → angry
    - sad → determined
    - confident → shocked
```
