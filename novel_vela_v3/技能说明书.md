# novel_vela_v3 技能说明书

## 一、技能概述

| 项目 | 内容 |
|------|------|
| **技能名称** | novel_vela_v3 |
| **核心功能** | AI小说创作全流程管理（V3融合版） |
| **定位** | 创作型技能 —— 从项目初始化到章节写作的完整工作流管理 |
| **技术栈** | Python 3.13 + click + sqlite3 + requests |
| **架构模式** | 两阶段协作模型：CLI建骨架 → AI填内容 |

## 二、核心能力

### 2.1 两阶段协作模型

```
阶段1（CLI工具层）：建骨架、管数据、出模板、RAG检索、审查同步
    ↓ 模板文件就位后
阶段2（AI内容层）：读模板、填内容、生成具体创作物
```

**关键原则**：
- CLI命令中的 `generate` = 生成模板文件（含占位符），不是生成最终内容
- 最终内容必须由 AI 读取模板后填充
- 两阶段必须按顺序执行

### 2.2 标准工作流（12步）

| 步骤 | 阶段 | 命令 | 说明 |
|------|------|------|------|
| ① | 1 | `init` | 创建项目目录 + 数据库 + 基础配置 |
| ② | 1 | `outline create` | 创建全书大纲.md（空模板） |
| ③ | 1 | `stage add` | 创建各阶段的阶段概要.md（空模板） |
| ④ | 1 | `blueprint init` | 创建各章的第XXX章蓝图.md（空模板） |
| ⑤ | 1 | `character add` | 向数据库添加人物记录 |
| ⑥ | 2 | AI读取 | 读取小说基本信息.md + 参考作品与文风.md |
| ⑦ | 2 | AI填充 | 填充全书大纲.md |
| ⑧ | 2 | AI填充 | 填充各阶段概要.md |
| ⑨ | 2 | AI填充 | 填充各章节蓝图.md |
| ⑩ | 2 | `context get` | 获取写作上下文报告（强制） |
| ⑪ | 2 | `write` | AI写作正文 |
| ⑫ | 2 | `audit sync` | 同步数据到Markdown |

### 2.3 核心功能模块

| 模块 | 说明 |
|------|------|
| **NovelDB** | 数据库操作类，11张核心表，支持上下文管理器 |
| **RAGRetriever** | 向量检索（sqlite-vec + Ollama nomic-embed-text，768维） |
| **ContextManager** | 动态上下文窗口（优先最近3章，累计≤10000字，最多5章） |
| **audit/sync** | 单章/批量审查 + DB与Markdown双向同步 |

### 2.4 数据库Schema（11张表）

`novels`, `stages`, `characters`, `maps`, `chapters`, `foreshadowing`, `character_relations`, `character_appearances`, `chapter_scenes`, `versions`, `rag_chunks`

### 2.5 上下文报告内容

1. 本章蓝图
2. 前文摘要（动态计算）
3. 活跃人物状态（排除已死亡，按重要度排序）
4. 待回收伏笔（status='planted'）
5. 当前地图信息
6. RAG召回设定（可选，需Ollama）
7. 文风提示

## 四、使用方式

```bash
# 初始化新项目（阶段1）
python scripts/novel_cli.py init "小说名" --genre "玄幻" --total-words 500000 --chapters 80

# 创建大纲模板（阶段1）
python scripts/novel_cli.py outline create

# 添加阶段（阶段1）
python scripts/novel_cli.py stage add 1 --name "废柴崛起" -s 1 -e 50

# 初始化章节蓝图（阶段1）
python scripts/novel_cli.py blueprint init 1 50

# 添加人物（阶段1）
python scripts/novel_cli.py character add "主角名" -t protagonist --importance 10

# 获取写作上下文（阶段2）
python scripts/novel_cli.py context get 1

# 写作准备（阶段2）
python scripts/novel_cli.py write 1

# RAG搜索（阶段2）
python scripts/novel_cli.py rag search "主角能力"

# 审查（阶段2）
python scripts/novel_cli.py audit chapter 1

# 同步（阶段2）
python scripts/novel_cli.py sync db-to-md
```

## 五、关键设计亮点

1. **两阶段模型清晰**：CLI建骨架 → AI填内容，职责分离明确
2. **单文件实现**：所有核心功能（DB/RAG/Context/CLI）集中在 novel_cli.py
3. **三层去AI味防护**：Prompt约束 + 文风学习 + 后处理修正
4. **智能路径处理**：自动识别三种路径模式（直接plan/novel.db、《书名》目录、子目录搜索）
5. **模板化设计**：所有创作物都是"空模板+占位符"，必须由AI填充
6. **V1+V2融合**：保留了V1的完整功能（RAG/audit/sync），同时明确了V2的两阶段模型

## 八、注意事项

1. **Python路径**：必须使用 `C:\Python\Python313\python.exe`
2. **依赖安装**：`C:\Python\Python313\python.exe -m pip install click requests sqlite-vec`
3. **RAG前提**：需要 Ollama 服务运行，否则 rag search 会提示未安装
4. **最重要**：`outline create` / `blueprint init` / `stage add` 只创建**空模板**，必须由 AI 填充实际内容
