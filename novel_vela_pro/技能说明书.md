# novel_vela_pro 技能说明书

## 一、技能概述

| 项目 | 内容 |
|------|------|
| **技能名称** | novel_vela_pro |
| **核心功能** | 工程化管理的AI小说创作工作台 |
| **定位** | 创作型技能 —— 从项目初始化到章节写作的完整工作流管理 |
| **技术栈** | Python 3.13 + click + httpx + sqlite-vec(可选) |
| **架构模式** | 工程化基础设施 + 创作指导能力 |

## 二、核心能力

### 2.1 12大功能模块

| 模块 | 命令 | 说明 |
|------|------|------|
| 项目初始化 | `init` | 创建完整项目结构，含数据库和模板 |
| 设定管理 | — | 核心设定、角色、世界观的分层管理 |
| 大纲规划 | `outline generate/show` | 全书大纲生成与管理 |
| 阶段规划 | `stage add/list` | 将大纲拆分为可管理的阶段 |
| 章节蓝图 | `blueprint generate/show` | 为每章生成详细写作蓝图 |
| 上下文管理 | `context get` | 写作前强制加载上下文报告 |
| RAG检索 | `rag search/rebuild/status/index` | 语义搜索设定，防止跑偏 |
| 审查复核 | `audit chapter/range` | 多维度质量检查 |
| 图解生成 | `diagram character/timeline` | Mermaid人物关系图、时间线 |
| 错误记录 | `error log/report` | 分类记录和追踪问题 |
| 记忆系统 | `learnings status/read` | .learnings/ 可读记忆文件管理 |
| 同步管理 | `sync db-to-md/check` | DB与Markdown双向同步 |

### 2.2 数据架构

- **SQLite**: 结构化数据存储（novels/stages/characters/chapters等11张表）
- **RAG**: 向量检索（sqlite-vec + Ollama nomic-embed-text，768维）
- **.learnings/**: 可读记忆文件（16个文件，3层架构：CORE/EXTENDED/STYLE）

## 四、使用方式

```bash
# 创建新项目
python scripts/novel_cli.py init "小说名称" --genre "玄幻" --words 4500000 --chapters 750

# 管理阶段
python scripts/novel_cli.py stage add 1 --name "废柴崛起" --start 1 --end 50

# 生成章节蓝图
python scripts/novel_cli.py blueprint generate 1 50

# 获取写作上下文
python scripts/novel_cli.py context get 1

# 审查章节
python scripts/novel_cli.py audit chapter 1

# 语义搜索设定
python scripts/novel_cli.py rag search "主角能力"

# 生成图解
python scripts/novel_cli.py diagram character
```

## 五、关键设计亮点

1. **工程化管理**：完整的项目目录结构 + SQLite数据库 + Markdown文档
2. **RAG向量检索**：防止写作时设定跑偏
3. **上下文强制加载**：写作前必须获取上下文报告
4. **.learnings记忆系统**：三层架构管理创作知识
5. **Mermaid图解**：自动生成人物关系图和剧情时间线
6. **错误追踪**：分类记录和追踪创作中的问题

## 六、依赖关系

- **前置技能**：novel_anaylsis_pro（风格分析结果可用于初始化时的文风参考）
- **后置技能**：novel_vela_v3（V3是V1+V2的融合版，功能更完善）
- **外部依赖**：Ollama（RAG向量检索需要）

## 七、与 novel_vela_v3 的关系

novel_vela_pro 是 V1 的增强版，融合了 novel-generator-pro 的创作指导能力。V3 在此基础上进一步明确了两阶段协作模型（CLI建骨架 → AI填内容）。
