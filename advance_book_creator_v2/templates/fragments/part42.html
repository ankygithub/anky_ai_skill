第四十二章 智能问数——归因分析与示例代码

7.6 归因分析流程与示例代码

归因分析是智能问数系统的高级能力之一，当检测到数据异常时，系统需要自动分析异常的原因并给出解释。本节从归因分析流程和示例代码两个维度展开。

7.6.1 归因分析的核心逻辑

归因分析不是让大模型"猜测"原因，而是先跑结构化的数据分析，再让模型基于分析结果进行解释。这是一个关键的设计原则。

💡 核心原则： 先跑结构化分析（按地区/渠道/品类/客户类型分解，计算贡献度），再让模型基于结果解释。永远不要跳过数据分析步骤直接让模型"编造"原因。

归因分析的标准流程：

检测到异常
       │
       ▼
┌─────────────────────────────────┐
│  第一步：结构化分解               │
│  按维度拆解指标，计算各维度贡献度   │
└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐
│  第二步：异常定位                 │
│  找出贡献度最大的异常维度          │
└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐
│  第三步：深度下钻                 │
│  对异常维度进行更细粒度的分析      │
└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐
│  第四步：模型解释                 │
│  让大模型基于分析结果生成解释      │
└────────────────┬────────────────┘
                 │
                 ▼
         输出归因分析报告

7.6.2 归因分析示例代码

以下是归因分析的核心实现：

class AttributionAnalyzer:
    """归因分析引擎"""

    def analyze(self, metric: str, anomaly: AnomalyInfo,
                dimensions: List[str], time_range: TimeRange) -> AttributionReport:
        """
        执行完整的归因分析流程
        
        Args:
            metric: 异常指标名称
            anomaly: 异常信息（指标值、预期值、偏离度）
            dimensions: 可用的分析维度列表
            time_range: 分析时间范围
            
        Returns:
            归因分析报告
        """
        # 第一步：结构化分解 - 按各维度计算贡献度
        dimension_contributions = []
        for dim in dimensions:
            contribution = self._calculate_dimension_contribution(
                metric=metric,
                dimension=dim,
                time_range=time_range,
                baseline=anomaly.baseline,
                actual=anomaly.actual
            )
            dimension_contributions.append(contribution)

        # 第二步：异常定位 - 找出贡献度最大的维度
        sorted_contributions = sorted(
            dimension_contributions,
            key=lambda c: abs(c.contribution_value),
            reverse=True
        )

        # 第三步：深度下钻 - 对异常维度进行更细粒度分析
        top_anomalies = []
        for contribution in sorted_contributions[:3]:  # 取前3个异常维度
            drill_down = self._drill_down(
                metric=metric,
                dimension=contribution.dimension,
                anomaly_value=contribution.contribution_value,
                time_range=time_range
            )
            top_anomalies.append(drill_down)

        # 第四步：模型解释 - 让大模型基于结构化结果生成解释
        explanation = self._generate_explanation(
            metric=metric,
            anomaly=anomaly,
            top_contributions=sorted_contributions[:3],
            drill_downs=top_anomalies
        )

        return AttributionReport(
            metric=metric,
            anomaly=anomaly,
            dimension_contributions=sorted_contributions,
            top_anomalies=top_anomalies,
            explanation=explanation,
            timestamp=datetime.now()
        )

    def _calculate_dimension_contribution(
        self, metric: str, dimension: str,
        time_range: TimeRange, baseline: float, actual: float
    ) -> DimensionContribution:
        """计算单个维度的贡献度"""
        # 查询该维度在基准期和当前期的数据
        baseline_data = self.query_metric(
            metric=metric,
            dimension=dimension,
            time_range=time_range.baseline_period
        )
        actual_data = self.query_metric(
            metric=metric,
            dimension=dimension,
            time_range=time_range.current_period
        )

        # 计算各维度值的贡献度
        contributions = []
        for dim_value in dimension.all_values():
            baseline_value = baseline_data.get(dim_value, 0)
            actual_value = actual_data.get(dim_value, 0)

            # 贡献度 = (当前值 - 基准值) / 总差异
            total_diff = actual - baseline
            if total_diff != 0:
                contribution = (actual_value - baseline_value) / total_diff
            else:
                contribution = 0

            contributions.append(DimensionValueContribution(
                dimension=dimension,
                value=dim_value,
                baseline=baseline_value,
                actual=actual_value,
                change_rate=(actual_value - baseline_value) / baseline_value if baseline_value > 0 else 0,
                contribution=contribution
            ))

        return DimensionContribution(
            dimension=dimension,
            values=contributions
        )

    def _generate_explanation(
        self, metric: str, anomaly: AnomalyInfo,
        top_contributions: List[DimensionContribution],
        drill_downs: List[DrillDownResult]
    ) -> str:
        """基于结构化分析结果生成归因解释"""
        # 构造结构化的分析摘要，作为模型输入
        analysis_summary = self._build_analysis_summary(
            metric=metric,
            anomaly=anomaly,
            top_contributions=top_contributions,
            drill_downs=drill_downs
        )

        prompt = f"""
作为数据分析专家，请基于以下结构化分析结果，生成归因分析报告。

注意：
1. 请严格基于提供的数据分析结果进行解释，不要猜测或编造原因
2. 按重要性排序说明各因素
3. 给出具体的数据和百分比
4. 最后给出建议

分析数据：
{analysis_summary}

请生成归因分析报告。
"""
        return self.llm.generate(prompt)

7.6.5 图表推荐规则

class ChartRecommender:
    """图表推荐引擎"""

    def recommend(self, query_result: QueryResult) -> ChartConfig:
        """根据查询结果推荐最合适的图表"""
        num_dimensions = len(query_result.dimensions)
        num_metrics = len(query_result.metrics)
        data_points = len(query_result.rows)

        # 单值指标 → 数字卡片
        if num_dimensions == 0 and num_metrics == 1:
            return ChartConfig(type="number_card", metrics=query_result.metrics)

        # 时间序列 → 折线图
        if any(d.type == "time" for d in query_result.dimensions) and num_metrics <= 3:
            return ChartConfig(type="line_chart", time_dim=query_result.time_dimension,
                               metrics=query_result.metrics)

        # 分类对比 → 柱状图
        if num_dimensions == 1 and num_metrics == 1 and data_points <= 20:
            return ChartConfig(type="bar_chart", dimension=query_result.dimensions[0],
                               metric=query_result.metrics[0])

        # 占比分析 → 饼图
        if num_dimensions == 1 and num_metrics == 1 and data_points <= 8:
            total = sum(r[query_result.metrics[0]] for r in query_result.rows)
            if any(r[query_result.metrics[0]] / total > 0.5 for r in query_result.rows):
                return ChartConfig(type="pie_chart", dimension=query_result.dimensions[0],
                                   metric=query_result.metrics[0])

        # 多维对比 → 堆叠柱状图
        if num_dimensions == 1 and num_metrics > 1:
            return ChartConfig(type="stacked_bar_chart",
                               dimension=query_result.dimensions[0],
                               metrics=query_result.metrics)

        # 地域分析 → 地图
        if any(d.name in ["region", "province", "city"] for d in query_result.dimensions):
            return ChartConfig(type="map_chart", dimension=query_result.region_dimension,
                               metric=query_result.metrics[0])

        # 默认 → 数据表格
        return ChartConfig(type="data_table", dimensions=query_result.dimensions,
                           metrics=query_result.metrics)

7.6.6 本章小结

归因分析遵循"先跑结构化分析，再让模型基于结果解释"的原则。结构化分解按维度计算贡献度，异常定位找出贡献度最大的维度，深度下钻进行更细粒度分析，最后由模型基于结构化结果生成解释。本章提供了语义层配置（指标定义YAML）、SQL校验规则配置和图表推荐规则的完整示例代码。这些代码和配置可以直接指导智能问数系统的技术实现。
