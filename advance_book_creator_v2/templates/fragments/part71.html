第12.3章 医疗AI——智能问诊与病历结构化

12.3.1 智能问诊的业务场景

传统问诊流程中，患者候诊时间长、就诊时间短，医生需要在有限的门诊时间内完成问诊、查体、开具检查/处方等一系列工作。智能问诊AI通过在诊前、诊中、诊后三个环节引入AI能力，优化问诊全流程：

诊前——智能预问诊：
  • 患者通过手机/自助机完成症状描述
  • AI基于知识图谱+大模型进行多轮追问（"症状持续多久了？""是否伴随发热？"）
  • 自动生成预问诊报告，包含主诉/现病史/既往史/过敏史
  • 医生接诊时可直接查看预问诊报告，节省问诊时间
诊中——多模态交互辅助：
  • 语音识别：实时转写医患对话，自动生成门诊病历草稿
  • 语义理解：识别关键医学术语（症状/体征/诊断/用药）
  • OCR识别：患者自带的外院检查报告/处方拍照识别
  • 病历结构化：自由文本病历自动转化为结构化字段
诊后——随访与康复指导：
  • 基于诊断自动生成随访计划（复查时间/复查项目）
  • 用药提醒与健康指导
  • 症状变化追踪与异常预警

12.3.2 医生个性化配置

不同科室、不同医生的问诊习惯和病历书写风格存在差异。智能问诊AI需支持个性化配置：

配置维度示例
科室模板内科/外科/儿科/妇产科/中医科各有专属问诊模板
问诊流程自定义问诊路径（先问主诉→再问既往史 vs 先问既往史→再问主诉）
病历格式自定义病历字段顺序和必填项
术语偏好医生习惯使用"上呼吸道感染" vs "感冒"
处方习惯常用药品/剂量/疗程偏好设置

12.3.3 病历结构化系统

病历结构化是医疗AI的核心基础能力。医院现有病历系统中存在大量非结构化文本（主诉/现病史/既往史/查体/诊断/医嘱），AI需要从这些文本中自动抽取结构化字段：

门诊病历结构化： 
{
  "visit_type": "门诊",
  "chief_complaint": "反复咳嗽2周，加重3天",
  "history_of_present_illness": {
    "onset": "2周前",
    "symptoms": ["咳嗽", "咳痰"],
    "aggravation": "3天前加重",
    "associated_symptoms": ["低热"],
    "treatment_history": "自行服用止咳药，效果不佳"
  },
  "past_medical_history": {
    "chronic_diseases": ["高血压"],
    "allergies": ["青霉素"],
    "surgeries": []
  },
  "physical_exam": {
    "temperature": 37.8,
    "lung_auscultation": "双肺呼吸音粗，未闻及干湿性啰音"
  },
  "diagnosis": "急性支气管炎",
  "icd_10": "J20.900"
}
住院病历结构化：
  • 入院记录：入院情况/入院诊断/诊疗计划
  • 病程记录：每日病情变化/医嘱变更/检查结果分析
  • 出院小结：入院情况/诊疗经过/出院诊断/出院医嘱
  • 手术记录：手术名称/手术方式/术中发现/术后处理
检查/检验报告字段抽取：
  • 检查报告：检查项目/检查方法/影像所见/诊断意见
  • 检验报告：检验项目/结果值/参考范围/异常标志

12.3.4 医学术语标准化

病历结构化的前提是医学术语标准化。同一概念在不同医生笔下可能有多种表达：

标准术语常见变体
"2型糖尿病""二型糖尿病"、"T2DM"、"非胰岛素依赖型糖尿病"
"高血压3级""三级高血压"、"重度高血压"、"BP 180/110"
"冠状动脉粥样硬化性心脏病""冠心病"、"CHD"、"缺血性心脏病"

AI系统需建立医学术语映射词典，将自由文本中的各种表达映射到标准术语（ICD-10/SNOMED CT/中医病证分类代码）。

12.3.5 病历辅助功能矩阵

功能描述价值
报告摘要将长篇幅病历浓缩为关键信息摘要快速了解患者概况
病程辅助基于昨日病历+今日检验自动生成病程草稿减少文书工作量
出院小结自动汇总住院期间诊疗经过节省30-50%书写时间
相似病例基于当前病历检索历史相似病例辅助诊疗决策
随访计划基于诊断自动生成随访方案规范化随访管理
数据质控检查病历完整性/一致性/规范性提升病历质量评分

[!NOTE] 病历结构化质量要求

病历字段抽取准确率需≥95%，关键字段（诊断/用药/过敏史）准确率需≥99%。错误抽取可能导致用药错误或误诊，需建立人工复核机制。

12.3.6 验收标准

指标目标值测量方法
预问诊报告完整率≥90%（核心字段填写完整）医生评分
语音转写准确率≥95%（医学术语场景）与人工录音对照
病历字段抽取准确率≥95%（关键字段≥99%）抽样人工复核
文书时间减少门诊病历书写时间减少30-50%上线前后对比
医生满意度≥80%认可AI辅助效果问卷调查
