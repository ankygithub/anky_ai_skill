15.2 零售AI——智能导购系统

15.2.1 智能导购的核心定位

智能导购是零售AI中直接面向消费者的核心场景，本质是"AI化身的金牌导购员"。它的目标不是简单地回答问题，而是通过精准的商品理解和用户意图识别，促成购买决策。

智能导购与通用AI客服的关键区别：

维度通用AI客服智能导购
核心目标解决问题促成交易
回复风格客观、中立引导性、推荐性
知识范围通用知识库商品知识+库存+价格+促销
输出要求准确即可必须解释"为什么推荐"

>
核心原则
>

智能导购不能只说"这款很好"，必须解释"为什么推荐"。没有理由的推荐等同于广告，不会建立用户信任。每次推荐都需要给出至少1-2个具体理由（如成分优势、用户好评、性价比等）。

>

15.2.2 智能导购的七大核心场景

场景一：需求澄清

用户进店时，需求往往是模糊的。智能导购的第一步是需求澄清——通过多轮对话，将模糊需求转化为精确的商品搜索条件。

用户说："我想买个面霜" AI导购需要追问：

  • 肤质是什么？（干性/油性/混合性/敏感性）
  • 预算范围？（平价/中端/高端）
  • 核心诉求？（保湿/美白/抗皱/祛痘）

需求澄清的质量直接决定了推荐准确度。好的需求澄清可以将推荐命中率从30%提升到70%以上。

场景二：商品推荐（结合库存和价格）

智能导购的核心能力是商品推荐。与通用推荐引擎不同，导购场景下的推荐必须实时结合库存和价格信息。

推荐逻辑：

1

意图理解

从用户对话中提取需求标签：品类、品牌偏好、价格区间、功能诉求。

2

候选召回

从商品库中召回匹配度高的商品（通常50-100个候选）。

3

库存过滤

过滤缺货商品，确保推荐的商品用户可购买。

4

价格排序

结合用户预算和促销信息，生成推荐排序。

5

推荐理由生成

为每个推荐商品生成1-2句推荐理由（为什么适合这个用户）。

场景三：商品对比

用户在多个商品间犹豫时，智能导购需要提供商品对比。对比维度包括：

  • 核心参数对比（成分/规格/功能）
  • 优缺点对比（客观陈述，不贬低竞品）
  • 适用人群对比（"A适合干皮，B适合油皮"）
  • 价格/性价比对比

对比输出的关键原则：客观、结构化、可操作。不能只列参数，要给出"如果你是XX需求，选A更合适"的建议。

场景四：搭配推荐 搭配推荐（组合购买）是提升客单价的核心手段。智能导购需要理解商品之间的搭配关系：
  • 互补搭配：洗面奶+爽肤水+面霜（护肤套装）
  • 场景搭配：防晒霜+遮阳帽+墨镜（出游场景）
  • 人群搭配：孕妇可用护肤品组合

搭配推荐的逻辑：

# 搭配推荐伪代码
def recommend_combination(cart_items, user_profile, inventory):
    """
    基于已购/已加购商品，推荐搭配商品
    """
    base_category = get_category(cart_items[0])
    
    # 从搭配知识图谱中查找关联商品
    related = knowledge_graph.query({
        "base_category": base_category,
        "relation_type": ["complementary", "scene_match"],
        "user_profile": user_profile  # 考虑肤质/预算等
    })
    
    # 过滤库存不足的商品
    in_stock = filter_by_inventory(related, inventory)
    
    # 按搭配相关度排序
    ranked = rank_by_relevance(in_stock, cart_items)
    
    return ranked[:3]  # 返回top3搭配推荐
场景五：评价摘要

用户面对数十条甚至数百条商品评价时，很难快速了解真实口碑。评价摘要功能通过AI提取评价中的核心信息：

  • 优点汇总（提取高频正面关键词）
  • 缺点汇总（提取高频负面关键词）
  • 适用人群（从评价中推断适合的使用场景）
  • 真实性检测（过滤刷单/水军评价）

评价摘要的输出格式：

👍 用户好评集中点：
- 保湿效果好（87%提及）
- 质地清爽不油腻（72%提及）
- 性价比高（65%提及）

👎 用户反馈不足：
- 包装简陋易破损（15%提及）
- 味道偏浓（12%提及）

📌 适合人群：干性/混合性肌肤，追求保湿效果的用户
场景六：购买引导 购买引导涵盖优惠查询、库存状态、配送时效等决策辅助信息：
  • 优惠信息：当前可用优惠券、满减活动、会员折扣
  • 库存状态：当前库存量、预计补货时间
  • 配送时效：预计到达时间、支持的配送方式
场景七：售后说明

售后环节的智能导购需要处理：

  • 退换货政策说明
  • 质保期限查询
  • 使用指导（产品使用方法、注意事项）
  • 投诉转接（当用户情绪激动时自动转人工）

15.2.3 智能导购的技术架构

用户输入 → 意图识别 → 场景路由
                       ├── 需求澄清 → 多轮对话引擎
                       ├── 商品推荐 → RAG+推荐引擎
                       ├── 商品对比 → 参数对比生成
                       ├── 搭配推荐 → 搭配知识图谱
                       ├── 评价摘要 → 评价NLP分析
                       ├── 购买引导 → 订单/库存API
                       └── 售后说明 → 售后知识库

15.2.4 产品经理的设计要点

设计要点说明
推荐理由必须有据可依每次推荐必须给出具体理由，不能空泛说"好"
库存和价格必须实时推荐的商品必须有货、价格准确
对比必须客观不贬低竞品，客观陈述优缺点
搭配推荐提升客单价通过搭配推荐将单件购买转化为组合购买
评价摘要增加信任真实的评价分析能显著提升用户信任度

15.2.5 本章小结

智能导购是零售AI的核心场景，覆盖需求澄清、商品推荐、商品对比、搭配推荐、评价摘要、购买引导、售后说明七个子场景。核心原则是"不能只说这款很好，要解释为什么推荐"。推荐必须结合实时库存和价格，对比必须客观，搭配推荐是提升客单价的关键手段。
