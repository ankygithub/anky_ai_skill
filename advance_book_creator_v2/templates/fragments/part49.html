8.5 结构化输出规范与示例代码

文档智能处理系统的最终输出必须是结构化的、机器可读的数据格式。本节定义标准的JSON输出Schema，并提供多模型流水线配置和低置信度复核队列的示例代码。

8.5.2 多模型流水线配置示例

# pipeline-config.yaml
# 文档智能处理流水线配置

pipeline:
  name: "contract_processing_v2"
  version: "2.3.0"
  
  stages:
    - name: "ocr"
      type: "parallel"  # OCR和版面分析可以并行
      models:
        - id: "ocr_engine"
          engine: "paddleocr"
          config:
            lang: "ch"
            use_angle_cls: true
            use_gpu: true
          timeout_ms: 30000
          retry: 1
          fallback:
            engine: "tesseract"
            config:
              lang: "chi_sim"

        - id: "layout_analyzer"
          engine: "layoutlmv3"
          config:
            model_path: "models/layoutlmv3-base-zh"
            detect_elements: ["title", "paragraph", "table", "seal", "signature", "header", "footer", "image"]
          timeout_ms: 20000
          retry: 1

    - name: "field_extraction"
      type: "sequential"  # 依赖OCR和版面分析结果
      extractors:
        # 正则抽取器（优先使用，速度快、准确率高）
        - id: "regex_extractor"
          type: "regex"
          fields:
            - name: "contract_date"
              patterns: ["(\d{4})年(\d{1,2})月(\d{1,2})日", "(\d{4}-\d{2}-\d{2})"]
            - name: "contract_number"
              patterns: ["合同编号[：:]\s*([A-Za-z0-9\-]+)", "编号[：:]\s*([A-Za-z0-9\-]+)"]
            - name: "amount"
              patterns: ["[¥￥]\s*([\d,]+\.?\d*)", "金额[：:]\s*([\d,]+\.?\d*)"]
          confidence_threshold: 0.85

        # NER抽取器
        - id: "ner_extractor"
          type: "ner"
          model: "roberta-ner-zh"
          fields:
            - name: "party_a"
              entity_type: "ORG"
              context: "甲方|买方|委托方"
            - name: "party_b"
              entity_type: "ORG"
              context: "乙方|卖方|受托方"
          confidence_threshold: 0.80

        # LLM抽取器（兜底，覆盖复杂场景）
        - id: "llm_extractor"
          type: "llm"
          model: "qwen-max-latest"
          prompt_template: |
            请从以下合同文本中提取以下字段：
            - 合同总金额
            - 付款方式
            - 付款节点
            - 交付时间
            - 违约责任
            
            合同文本：
            {contract_text}
            
            请以JSON格式输出，每个字段包含value和confidence。
          max_tokens: 2000
          temperature: 0.1
          confidence_threshold: 0.70
          fallback_mode: true  # 仅当regex和ner未覆盖时使用

    - name: "risk_analysis"
      type: "parallel"  # 大模型分析和规则引擎并行
      analyzers:
        - id: "llm_risk_analyzer"
          type: "llm"
          model: "qwen-max-latest"
          prompt_template: |
            你是一位资深法务专家。请分析以下合同条款是否存在法律风险。
            
            条款内容：
            {clause_text}
            
            请从以下维度分析：
            1. 风险类型
            2. 严重程度
            3. 法律依据
            4. 修改建议
            
            输出JSON格式。
          max_tokens: 1500
          temperature: 0.1
          risk_types:
            - "unbalanced_liability"
            - "excessive_penalty"
            - "missing_clause"
            - "ambiguous_terms"
            - "data_security"
            - "auto_renewal"

        - id: "rule_engine"
          type: "rules"
          engine: "drools"
          rule_files:
            - "rules/compliance-rules-v2.3.drl"
            - "rules/enterprise-standards.drl"
            - "rules/industry-specific-rules.drl"

    - name: "result_assembly"
      type: "sequential"
      assembler:
        schema_version: "draft-07"
        output_format: "json"
        include_metadata: true

8.5.3 低置信度复核队列逻辑

class LowConfidenceReviewQueue:
    """低置信度字段人工复核队列"""
    
    def __init__(self, db, notification_service):
        self.db = db
        self.notification_service = notification_service
        self.low_threshold = 0.70
        self.very_low_threshold = 0.50
    
    def process_extraction_result(self, result: ContractExtractionResult):
        """处理抽取结果，将低置信度字段加入复核队列"""
        review_tasks = []
        
        for field in result.fields:
            if field.confidence < self.low_threshold:
                task = self.create_review_task(field, result.document_id)
                review_tasks.append(task)
                self.db.review_tasks.insert(task)
        
        # 如果有需要复核的任务，通知相关人员
        if review_tasks:
            self.notification_service.notify(
                recipients=self.get_reviewers(result.document_type),
                subject=f"文档 {result.document_id} 需要人工复核",
                task_count=len(review_tasks),
                priority=self.calculate_overall_priority(review_tasks)
            )
        
        # 更新文档状态
        self.db.documents.update(
            document_id=result.document_id,
            review_status="pending_review" if review_tasks else "auto_passed",
            review_tasks=review_tasks
        )
        
        return review_tasks
    
    def create_review_task(self, field: ExtractedField, document_id: str) -> ReviewTask:
        """创建复核任务"""
        priority = self.calculate_field_priority(field.field_type)
        
        return ReviewTask(
            task_id=f"REV-{document_id}-{field.field_name}",
            document_id=document_id,
            field_name=field.field_name,
            field_type=field.field_type,
            ai_value=field.value,
            ai_confidence=field.confidence,
            source_page=field.source_page,
            source_location=field.source_location,
            original_document_url=self.get_document_preview_url(document_id, field.source_page),
            text_snippet=field.source_location.get("text_snippet", ""),
            priority=priority,
            status="pending",
            created_at=datetime.now(),
            assigned_to=None
        )
    
    def calculate_field_priority(self, field_type: str) -> int:
        """根据字段类型计算复核优先级"""
        priority_map = {
            # 财务相关字段 - 最高优先级
            "contract_amount": 10,
            "payment_terms": 9,
            "payment_schedule": 9,
            "tax_rate": 8,
            # 法律责任字段 - 高优先级
            "violation_liability": 8,
            "penalty_rate": 8,
            "dispute_resolution": 7,
            # 主体信息字段 - 中高优先级
            "party_a": 7,
            "party_b": 7,
            "credit_code": 7,
            # 其他字段 - 中低优先级
            "contract_date": 5,
            "contact_person": 4,
            "contact_phone": 3,
            "address": 4,
        }
        return priority_map.get(field_type, 5)
    
    def submit_review_result(self, task_id: str, human_value, confirmed: bool, reviewer_id: str):
        """提交人工复核结果"""
        task = self.db.review_tasks.get(task_id)
        if not task:
            raise ValueError(f"复核任务不存在: {task_id}")
        
        task.status = "reviewed_confirmed" if confirmed else "reviewed_corrected"
        task.human_value = human_value
        task.reviewer_id = reviewer_id
        task.reviewed_at = datetime.now()
        
        self.db.review_tasks.update(task)
        
        # 将结果写入标注数据表，用于模型优化
        self.save_annotation_data(task)
        
        # 检查该文档的所有复核任务是否已完成
        self.check_document_review_completion(task.document_id)
    
    def save_annotation_data(self, task: ReviewTask):
        """保存标注数据用于模型优化"""
        annotation = AnnotationRecord(
            document_id=task.document_id,
            field_name=task.field_name,
            field_type=task.field_type,
            original_text=task.text_snippet,
            ai_value=task.ai_value,
            ai_confidence=task.ai_confidence,
            human_value=task.human_value,
            is_corrected=task.status == "reviewed_corrected",
            source_page=task.source_page,
            annotated_by=task.reviewer_id,
            annotated_at=task.reviewed_at,
            annotation_version="v1.0"
        )
        self.db.annotations.insert(annotation)

8.5.4 本章小结

文档智能处理系统的结构化输出采用统一的JSON Schema，每个字段包含原文位置、置信度、来源页码和人工确认状态。低置信度字段自动进入人工复核队列，按字段重要性排序优先级。复核结果作为标注数据回流到模型训练流程。多模型流水线通过YAML配置管理，支持模型热切换和降级策略。
