# SVG图形PRO (SVG_PRO)

## 核心工作流

1. **识别图表类型**: 根据用户需求判断属于哪种图表类型（见下方图表类型速查）
2. **加载规范**: 读取对应图表类型的布局规范（`references/layout-system.md` 中查找对应类型）
3. **组合提示词**: 从5个分类（布局策略、间距边界、文字处理、连线路由、自适应）中提取相关提示词
4. **生成SVG**: 基于模板和规范生成SVG代码
5. **质量检查**: 对照下方质量检查清单自检
6. **输出交付**: 提供可离线打开的 `.svg` 文件

## 提示词组合公式

生成SVG前，必须组合以下5类提示词：

```
[图表类型] + [布局策略] + [间距边界] + [文字处理] + [连线路由] + [自适应] + [通用规范]
```

示例（系统分层架构图）：
```
生成系统分层架构图SVG。
布局策略：纵向分层，上层靠近用户，下层靠近底层。同层模块水平排列。
间距边界：层间距 ≥ 层内最高模块高度的1.5倍；同层模块水平等间距，间距 ≥ 最宽模块宽度；画布四周保留40px边距。
文字处理：标题14px，正文12px，标签10px；文字标签与图形边界保留8px padding；文字与背景色对比度 ≥ 4.5:1。
连线路由：跨层连线优先垂直，水平偏移 ≥ 模块间距；连线标签放中点加白色遮罩。
自适应：模块数量 > 5 时，自动分两行排列；节点高度随内容自适应，最小高度40px。
通用规范：设置viewBox="0 0 width height"；中文使用UTF-8编码；层次清晰，图形不重叠或覆盖，无溢出。
```

## 质量检查清单（生成后必须检查）

- [ ] viewBox 正确设置，确保缩放正常
- [ ] 层次清晰，图形不重叠或覆盖
- [ ] 无溢出（所有元素在画布边界内）
- [ ] 文字无遮挡（不被其他图形或连线遮挡）
- [ ] 文字无异常换行（在预期范围内自动换行）
- [ ] 连线清晰，无交叉混乱
- [ ] 颜色对比度足够（≥ 4.5:1）
- [ ] 中文显示正常（UTF-8 或 XML 数字字符引用）

## 故障排查

| 问题 | 解决方案 |
|------|---------|
| 图形重叠 | 检查间距常量是否满足；增加层间距或模块间距 |
| 文字溢出 | 增加节点宽度或高度；启用自动换行；减小字体 |
| 文字遮挡 | 调整元素层级（z-index）；为标签添加白色背景遮罩 |
| 连线交叉 | 使用贝塞尔曲线；调整节点位置；增加画布尺寸 |
| 中文乱码 | 确保文件声明UTF-8；或使用XML数字字符引用 |
