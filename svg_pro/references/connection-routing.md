# 连线与路由规则

本文档定义SVG技术图表中的连线走向、曲线类型、标签处理规范，确保连线清晰、不交叉混乱、标签可读。

## 通用连线规范

### 连线层级
```svg
<!-- 连线应在图形层之下，文字标签层之上 -->
<g class="lines">
  <line ... />
  <path ... />
</g>
<g class="line-labels">
  <text ... />
</g>
```

### 连线样式
| 线型 | 用途 | SVG属性 |
|------|------|---------|
| 实线 | 正常流向、直接关联 | `stroke="#666" stroke-width="1.5"` |
| 虚线 | 依赖、弱关联、可选路径 | `stroke="#999" stroke-width="1" stroke-dasharray="5,3"` |
| 粗实线 | 核心路径、主数据流 | `stroke="#333" stroke-width="2.5"` |
| 点线 | 间接关系、后台任务 | `stroke="#bbb" stroke-width="1" stroke-dasharray="2,2"` |

### 箭头样式
| 箭头类型 | 用途 | SVG标记 |
|---------|------|---------|
| 普通箭头 | 单向流向 | `<marker refX="10" ...><path d="M0,0 L10,5 L0,10" /></marker>` |
| 空心三角 | 继承、实现 | `<marker ...><path d="M0,0 L10,5 L0,10" fill="white" /></marker>` |
| 菱形箭头 | 聚合、组合 | `<marker ...><path d="M0,5 L5,0 L10,5 L5,10" /></marker>` |
| 开放箭头 | 依赖 | `<marker ...><path d="M0,0 L10,5 L0,10" fill="none" /></marker>` |

## 系统分层架构图连线

### 跨层连线
- 优先使用**垂直直线**
- 水平偏移 ≥ 模块间距（避免穿越其他模块）
- 多条连线从同一模块出发时，水平分散排列，间距 ≥ 8px

```svg
<!-- 垂直跨层连线示例 -->
<line x1="200" y1="120" x2="200" y2="200" stroke="#666" stroke-width="1.5"
      marker-end="url(#arrow)" />
```

### 同层连线
- 使用**水平直线**或**轻微贝塞尔曲线**
- 避免穿越其他模块，必要时绕行

### 连线标签
- 放连线中点
- 背景加白色矩形遮罩（`fill="white" opacity="0.9"`）
- 字体大小 10px

## 流程图连线

### 主流向连线
- 使用**直线**或**轻微贝塞尔曲线**
- 曲线控制点偏移 = 节点间距 × 0.2

```svg
<!-- 贝塞尔曲线流向 -->
<path d="M 200 100 Q 250 100 250 150 T 300 200" 
      stroke="#666" fill="none" marker-end="url(#arrow)" />
```

### 判断分支连线
- 从菱形判断节点的四个角出发
- 标注"是/Yes"或"否/No"
- 分支标签放连线起点附近

### 回环连线
- 走节点**右侧**
- 使用**弧形**，半径 ≥ 30px
- 弧形高度 = 节点高度 + 40px

```svg
<!-- 右侧回环 -->
<path d="M 250 150 C 320 150, 320 50, 250 50" 
      stroke="#666" fill="none" marker-end="url(#arrow)" />
```

## 类图连线

### 继承线
- **垂直向下**
- 末端空心三角箭头
- 从子类顶部中心到父类底部中心

```svg
<line x1="200" y1="200" x2="200" y2="150" 
      stroke="#666" marker-end="url(#inherit-arrow)" />
```

### 关联线
- **水平或垂直**
- 末端普通箭头（单向）或无箭头（双向）
- 连线标签放中点，背景加白色遮罩

### 依赖线
- **虚线**（`stroke-dasharray="5,3"`）
- 末端开放箭头
- 通常从使用类指向被使用类

---

## 拓扑图连线

### 中心到边缘
- 使用**直线**
- 从中心节点边缘到边缘节点边缘
- 多条连线汇聚时，使用**贝塞尔曲线分流**

```svg
<!-- 贝塞尔分流 -->
<path d="M 400 300 Q 450 300 500 250" stroke="#666" fill="none" />
<path d="M 400 300 Q 450 300 500 350" stroke="#666" fill="none" />
```

### 边缘之间
- 使用**虚线**或**浅色线**表示间接关系
- 避免穿越中心节点

---

## 状态机连线

### 转移线
- 使用**弧形**（弧形高度 = 节点间距 × 0.3）
- 从源状态边缘到目标状态边缘

```svg
<!-- 弧形转移线 -->
<path d="M 150 200 Q 200 240 250 200" 
      stroke="#666" fill="none" marker-end="url(#arrow)" />
```

### 自环
- 放节点**上方**
- 半径 25-35px
- 事件标签放自环顶部

```svg
<!-- 上方自环 -->
<path d="M 180 150 C 180 110, 220 110, 220 150" 
      stroke="#666" fill="none" marker-end="url(#arrow)" />
```

### 双向转移
- 使用**上下两条弧线**区分
- 上弧线：A → B
- 下弧线：B → A

---

## 思维导图连线

### 曲线类型
- 使用**平滑贝塞尔曲线**或**椭圆弧**
- 从父节点边缘出发，到子节点边缘结束

```svg
<!-- 贝塞尔曲线连接 -->
<path d="M 400 300 C 450 300, 450 250 500 250" 
      stroke="#999" fill="none" stroke-width="1.5" />
```

### 避免穿越
- 连线不得穿越其他节点
- 必要时增加控制点调整曲线走向

---

## 甘特图连线

### 依赖连线
- 使用**虚线**连接相关任务条
- 从前置任务条末端到后续任务条始端
- 垂直下降 → 水平连接 → 垂直上升

```svg
<!-- 任务依赖连线 -->
<polyline points="300,120 320,120 320,160 340,160" 
          stroke="#999" fill="none" stroke-dasharray="3,3" />
```

---

## 数据图表连线

### 饼图/环形图标签引线
- 从扇区边缘中点出发
- 水平延伸后垂直指向标签
- 引线长度 = 10-20px

```svg
<!-- 引线示例 -->
<line x1="扇区边缘X" y1="扇区边缘Y" x2="标签X" y2="标签Y" stroke="#666" />
```

---

## 连线标签通用规则

### 位置
- 直线标签：放连线中点
- 曲线标签：放曲线中点，沿切线方向排列
- 弧形标签：放弧形最高点

### 背景遮罩
当标签与连线颜色相近时，必须添加遮罩：
```svg
<g>
  <!-- 计算标签背景矩形位置和大小 -->
  <rect x="标签X-2" y="标签Y-10" width="文字宽度+4" height="14" 
        fill="white" opacity="0.9" />
  <text x="标签X" y="标签Y" font-size="10">标签文字</text>
</g>
```

### 标签不重叠
- 相邻标签间距 ≥ 20px
- 标签不得超出画布边界
- 标签不得遮挡其他图形或文字
