# 文字处理规则

本文档定义SVG技术图表中的文字处理规范，确保文字清晰可读、无遮挡、无异常换行。

## 字体大小规范

| 元素类型 | 字体大小 | 字重 | 对齐方式 |
|---------|---------|------|---------|
| 图表标题 | 16px | bold | 居中 |
| 层级/分组标题 | 14px | bold | 居中或左对齐 |
| 节点标题/类名 | 14px | bold | 居中 |
| 正文内容 | 12px | normal | 左对齐 |
| 属性/方法列表 | 12px | normal | 左对齐 |
| 标签/标注 | 10px | normal | 居中或沿连线方向 |
| 轴标签/刻度 | 10px | normal | 居中 |

## 文字与边界间距

- 文字与图形边界保留 **8px** padding
- 多行文字行间距 = 字体大小 × 1.4
- 文字区域最小高度 = 字体大小 + 16px（上下各8px）

## 换行规则

### 自动换行触发条件
- 文字长度超过容器宽度 - 16px（左右各8px padding）
- 单词/中文词语优先整体换行，不在单个字符处截断

### 各图表类型换行策略

| 图表类型 | 最大行宽 | 换行行为 |
|---------|---------|---------|
| 系统分层架构图 | 模块宽度 - 16px | 自动换行，最多3行，超出截断 |
| 流程图 | 节点宽度 - 16px | 自动换行，菱形节点最多2行 |
| 类图 | 类节点宽度 - 16px | 属性/方法列表每项独立一行，不换行 |
| 拓扑图 | 节点宽度 - 16px | 自动换行，最多2行 |
| 状态机 | 节点宽度 - 16px | 自动换行，最多2行 |
| 思维导图 | 节点宽度 - 16px | 自动换行，最多3行 |
| 甘特图 | 任务列表宽度 - 16px | 任务名称不换行，超出截断加省略号 |
| 数据图表 | 扇区/柱体可用空间 | 标签最多1行，超出使用引线 |

## 文字遮挡预防

### 层级策略（z-index）
```svg
<!-- 文字层应在图形层之上 -->
<g class="shapes"><!-- 矩形、圆形等 --></g>
<g class="lines"><!-- 连线 --></g>
<g class="labels"><!-- 文字标签 --></g>
```

### 背景遮罩
当文字必须放在连线上方时，添加白色矩形遮罩：
```svg
<g>
  <line x1="100" y1="100" x2="200" y2="200" stroke="#666"/>
  <rect x="140" y="92" width="40" height="16" fill="white" opacity="0.9"/>
  <text x="160" y="104" text-anchor="middle" font-size="10">标签</text>
</g>
```

### 引线标注
当标签无法放入图形内部时，使用引线：
```svg
<line x1="扇区边缘" y1="..." x2="标签位置" y2="..." stroke="#666" stroke-width="1"/>
<text x="标签位置" y="..." font-size="10">标签文字</text>
```

## 对比度要求

- 文字与背景色对比度 ≥ **4.5:1**（符合WCAG AA标准）
- 常用配色对比度速查：

| 背景色 | 推荐文字色 | 对比度 |
|--------|-----------|--------|
| #FFFFFF（白） | #333333 | 12.6:1 |
| #F5F5F5（浅灰） | #333333 | 11.2:1 |
| #E3F2FD（浅蓝） | #1565C0 | 4.6:1 |
| #E8F5E9（浅绿） | #2E7D32 | 4.7:1 |
| #FFF3E0（浅橙） | #E65100 | 4.8:1 |
| #333333（深灰） | #FFFFFF | 12.6:1 |
| #1565C0（蓝） | #FFFFFF | 6.3:1 |
| #2E7D32（绿） | #FFFFFF | 4.9:1 |

## 中文处理

### 编码方式
- 首选：文件声明 UTF-8 编码 `<?xml version="1.0" encoding="UTF-8"?>`
- 备选：使用 XML 数字字符引用（如 `&#x6743;&#x9650;` 表示"权限"）

### 中文字体栈
```svg
<text font-family="'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif">
```

### 中文排版
- 避免在中文词语中间换行
- 标点符号不置于行首
- 中英文混排时保留适当字间距

## 文字溢出检测

生成SVG后，检查以下情况：
- [ ] 文字宽度 < 容器宽度 - 16px
- [ ] 文字高度 < 容器高度 - 16px
- [ ] 文字不被其他图形或连线遮挡
- [ ] 文字不在画布边界外
