# 布局系统总览

本文档定义8种技术图表类型的布局算法。生成SVG前，必须根据图表类型选择对应的布局规范。

---

## 系统分层架构图

### 布局算法
1. 确定层数（常见2-5层）
2. 计算每层最大模块高度和宽度
3. 从上至下排列层级，层间距 = max(层内最高模块高度 × 1.5, 60px)
4. 每层内模块水平等间距排列，间距 = max(最宽模块宽度, 40px)
5. 计算总画布尺寸：宽度 = 左右边距 + 模块总宽度 + 间距总和；高度 = 上下边距 + 层总高度 + 层间距总和

### 对齐规则
- 同层模块顶部对齐
- 层标题水平居中于该层
- 若模块数量 > 5，自动分两行排列，行间距 = 模块高度 + 20px

### 连线规则
- 跨层连线优先垂直
- 水平偏移 ≥ 模块间距
- 避免穿越其他模块

## 流程图

### 布局算法
1. 确定流向方向（默认从左到右）
2. 按步骤顺序排列节点
3. 判断节点（菱形）宽度 = 高度 × 1.4
4. 分支节点水平对齐于判断节点下方
5. 合并节点对齐于分支末端

### 间距规则
- 节点间最小间距：水平 60px，垂直 40px
- 判断节点与分支节点垂直间距 ≥ 50px
- 画布边距 40px

### 连线规则
- 主流向使用直线或轻微贝塞尔曲线
- 回环连线走右侧，弧形半径 ≥ 30px
- 判断分支标注"是/否"或"Yes/No"，放连线中点

## 类图

### 布局算法
1. 按继承层次垂直排列，父类在上，子类在下
2. 同一继承链左对齐
3. 无继承关系的类按关联关系水平排列
4. 类节点宽度固定（默认 160px），高度随属性/方法数量自适应

### 间距规则
- 类间水平间距 ≥ 180px（含类宽度）
- 继承层次垂直间距 ≥ 60px
- 关联类水平间距 ≥ 200px

### 连线规则
- 继承线：垂直向下，末端空心三角箭头
- 关联线：水平或垂直，末端普通箭头或无箭头
- 依赖线：虚线，末端开放箭头
- 连线标签放中点，背景加白色矩形遮罩（fill="white"，opacity="0.9"）

### 文字规则
- 类名：14px，加粗，居中
- 属性/方法：12px，左对齐
- 分隔线：属性区和方法区之间加 1px 实线
- 自动换行：最大行宽 = 节点宽度 - 16px

## 拓扑图

### 布局算法
1. 识别中心节点（网关、负载均衡器等）
2. 中心节点放置画布中央
3. 边缘节点按类型分组，等角度分布于中心周围
4. 同类型节点放在同一扇形区域

### 间距规则
- 中心节点与边缘节点间距 ≥ 100px
- 边缘节点间最小间距 ≥ 60px
- 画布边距 60px（因节点可能呈圆形分布）

### 连线规则
- 中心到边缘使用直线
- 边缘之间使用虚线或轻色线表示间接关系
- 多条连线汇聚时使用贝塞尔曲线分流

## 状态机

### 布局算法
1. 按生命周期顺序横向排列（初始 → 中间状态 → 终止）
2. 初始状态放最左侧，终止状态放最右侧
3. 复杂状态机可使用环形布局

### 间距规则
- 状态节点间最小间距 80px
- 初始/终止状态与其他状态间距 ≥ 100px
- 画布边距 50px

### 连线规则
- 转移线使用弧形（弧形高度 = 节点间距 × 0.3）
- 自环放节点上方，半径 25-35px
- 双向转移使用上下两条弧线区分
- 事件标签沿弧线中点切线方向排列

## 思维导图

### 布局算法
1. 中心主题放画布中央
2. 一级子节点均匀分布于中心周围（360° / 子节点数）
3. 二级及以下子节点继续向外辐射
4. 同一父节点的子节点扇形展开，扇形角度 = 360° / 同级节点数

### 间距规则
- 中心到一级子节点距离 ≥ 120px
- 层级间距（父到子）≥ 80px
- 同级节点间距 ≥ 节点宽度 + 30px

### 连线规则
- 使用平滑曲线（贝塞尔或椭圆弧）
- 连线从父节点边缘出发，到子节点边缘结束
- 避免穿越其他节点

### 自适应
- 深度 > 3 时，自动扩展画布尺寸
- 节点数量不均衡时，自动调整扇形角度分配

## 甘特图

### 布局算法
1. 左侧任务列表，右侧时间轴
2. 任务列表宽度固定（默认 200px）
3. 时间轴按日期等分刻度
4. 任务条形左对齐于开始时间，长度 = 持续时间 × 刻度宽度

### 间距规则
- 任务行高 ≥ 40px
- 任务条形高度 = 行高 × 0.6
- 任务条形垂直居中于行内
- 时间轴刻度间距 ≥ 40px（日）/ 20px（周）/ 10px（月）

### 对齐规则
- 任务名称左对齐，垂直居中于行内
- 任务条形左对齐于开始时间刻度
- 里程碑标记为菱形，居中于日期刻度

### 自适应
- 时间跨度 > 30 天，自动切换为周刻度
- 时间跨度 > 180 天，自动切换为月刻度

## 数据图表

### 饼图/环形图
1. 数据从大到小排列（12点方向开始，顺时针）
2. 扇区角度 = (数值 / 总和) × 360°
3. 环形图内径 = 外径 × 0.5

### 柱状图
1. 数据从左到右排列
2. 柱宽 = (画布宽度 - 边距 - 间距总和) / 数据项数
3. 柱间距 = 柱宽 × 0.3
4. 柱高 = (数值 / 最大值) × 可用高度

### 间距规则
- 图例与图表间距 ≥ 30px
- 数据标签与图形间距 ≥ 8px
- 画布边距：上 40px，下 60px（留轴标签空间），左右 40px

### 文字规则
- 数据标签：12px，放扇区内部（大扇区）或外部引线（小扇区）
- 图例：12px，垂直或水平排列
- 轴标签：10px

### 自适应
- 数据项 > 8 时，启用图例滚动或换行
- 小比例扇区（< 5%）合并为"其他"
