# 文抄公创作风格辅助Skill（整合版）

## 核心定位

文抄公，**借鉴流中的爽文写手**，以"稳、快、爽"著称。代表作：《武林半侠传》《巫界术士》《主神崛起》《逍遥梦路》《神秘之劫》《苟在妖武乱世修仙》等。

**核心风格标签：**
- ✅ 快节奏爽文：剧情紧凑、冲突密集、爽点频繁
- ✅ 强设定弱文学：设定详细严谨，语言简洁明快
- ✅ 极度理性+精致利己型主角：利益最大化是第一准则
- ✅ 谨慎苟道+杀伐果断：不惹事但也不怕事，该杀则杀
- ✅ 善于布局+幕后黑手：常走幕后大佬路线
- ✅ 缝合创新+本土化改造：借鉴热门元素+二次加工
- ⚠️ 人物工具化+情感表达偏淡（需要注意）

---

## 使用场景

1. **武侠/仙侠/玄幻**网文创作
2. **系统流/金手指流/苟道流/稳健流**写作
3. **无限流/诸天流/两界流**构建
4. **主角理性冷静型**故事创作
5. **快节奏爽文+设定驱动型**作品

## 核心创作原则

### 1. 叙事节奏：快、稳、爽

**节奏特点：**
- 开局即入戏，快速建立危机感
- 打脸与升级点密集（前中期极强）
- 主线清晰，副本推进干脆利落
- 剧情环环相扣，爽点密集不拖沓

**章节结构：**
```
【开头】承接上文 → 引入危机
【发展】金手指/能力 → 解决问题
【高潮】战斗/冲突/打脸
【结尾】收获 → 新危机 → 悬念钩子
```

### 2. 主角塑造：理性、苟道、利己

**核心人格画像：**
- **极度理性**：行事以利益最大化为核心，情感让位于生存与变强
- **谨慎苟道**：擅长隐藏实力，避免无谓消耗，伺机而动
- **杀伐果断**：对敌不做过多犹豫，能杀则杀，绝不圣母
- **善于布局**：常走幕后黑手路线，通过代理人或组织施加影响
- **目标明确**：核心目标为"超脱/长生/最高力量"
- **情绪内敛**：心理活动服务于决策逻辑，少大段独白

**行为模式：**
```
评估风险→计算收益→制定计划→坚决执行→收割成果→低调发育
```

### 3. 世界观设定：缝合+本土化

**核心技巧：**
- 借鉴热门元素（无限流/巫师流/苟道流）
- 本土化改造（气运/命格/东方修道/华夏元素）
- 二次加工形成自己的"组合拳"
- 力量体系清晰、世界观相对完整

**力量体系特点：**
- 明确的等级划分（先天/后天/宗师等）
- 数据化呈现：使用"芯片""系统""面板"量化能力
- 弱肉强食：实力为尊的丛林法则

### 4. 语言风格：高效信息通道

**特点：**
- 简洁明快、流畅直白
- 短句为主、信息密度高
- 白话为主、少繁复修辞
- 对话功能性强、服务剧情
- 整体情绪偏克制、少抒情独白

## 经典套路库

### 1. 开局套路

**穿越重生型：**
```
开局惨（被欺负/废物/将死）→ 获金手指（系统/芯片/特殊能力）→
快速提升→打脸挑衅者→定目标（超脱/长生/最高力量）
```

**本土崛起型：**
```
底层处境→意外机缘→初步提升→解决眼前危机→埋下伏笔
```

### 2. 打脸套路

**扮猪吃虎型：**
```
隐藏实力→被挑衅→关键爆发→反杀打脸→震惊众人
```

**越级挑战型：**
```
实力差距→智慧布局→凭借金手指→以弱胜强→创造奇迹
```

**反杀型：**
```
反派以为胜券在握→主角底牌尽出→反杀成功→反派震惊
```

### 3. 升级套路

**境界突破型：**
```
积累足够→寻找安全地→突破瓶颈→实力质变→测试新能力
```

**资源获取型：**
```
发现线索→准备探索→进入险地→遭遇危险→解决问题→获得宝物→安全撤离
```

### 4. 经典流程

**文抄公式经典流程（概括化）：**
```
开局弱→获金手指/身份→一路升级碾压、布局→换地图→继续碾压
→后期世界级高度时开小号重来→导致重复感（需要注意）
```

## 爽点设置指南

### 小高潮（每3-5章）
- ✅ 实力提升：境界突破、学会新功法
- ✅ 打脸爽：反杀挑衅者、揭穿阴谋
- ✅ 收获爽：寻宝获得、资源获取
- ✅ 身份提升：晋升、成名

### 大高潮（每30-50章）
- ✅ 境界大突破：跨越一个大境界
- ✅ 重大复仇：击杀宿敌
- ✅ 地图切换：进入更高级世界
- ✅ 身份揭露：隐藏身份曝光

## 注意事项（优缺点平衡）

### 优点（爽文读者最看重）
- 更新稳定、量大管饱
- 设定新颖、组合感强
- 前中期节奏爽点密度高

### 争议点（也是需要注意）
- 人物工具化、情感表达偏淡
- 文学性不高、匠气重
- 后期易平、重复感强

### 改善建议
- 关键配角可以赋予复杂背景
- 偶尔增加情感互动但不喧宾夺主
- 后期地图切换时增加新元素、避免重复
- 控制节奏，避免过度工具化
- 缝合元素时保持逻辑自洽
- 保持冷静基调，避免浓烈抒情
