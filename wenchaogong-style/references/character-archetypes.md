# 文抄公式主角人设构建指南（整合版）

## 核心主角画像

### 1. 极度理性+精致利己型（最典型）

**核心特征：**
- **目标明确：** 核心目标为"超脱/长生/最高力量"，其余皆为过渡
- **行事原则：** 优先自保与收益，计算成本与风险，绝不被"道义""感情"拖慢节奏
- **利益计算：** 行事以利益最大化为核心，情感让位于生存与变强
- **典型评价：** 精致利己、死道友不死贫道、从不圣母、差不多就帮一把

**行为模式：**
```
1. 评估风险收益比 → 2. 制定详细计划 → 3. 坚决执行
4. 收获战利品 → 5. 低调消化提升 → 6. 准备下一次行动
```

**心理活动描写：**
```
"这老狐狸果然不简单，他说这话必有深意..."
"实力差距太大，硬拼必死，还是先撤为妙..."
"此事风险与收益并存，还需从长计议..."
"此人既然得罪我，便斩草除根，以绝后患！"
```

**典型台词风格：**
- "此事……还需从长计议。"
- "既然已经结仇，那便斩草除根！"
- "实力不足，只能暂避锋芒。"
- "这倒是个机缘……"

### 2. 谨慎苟道+稳健发育型

**核心特征：**
- 大量作品归入"苟道流""稳健流"
- 强调"低风险、多准备、藏底牌"
- 主动压低存在感、建设安全屋、多方储备退路
- 甚至以寿命/时间换取稳健发育

**苟道行为模式：**
```
低调发育 → 收集信息 → 隐藏底牌 → 评估风险 → 果断出击 → 再次低调
```

### 3. 杀伐果断+情绪淡漠型

**核心特征：**
- 对敌不做过多犹豫，能杀则杀
- 必要时不介意"掀桌"或突破常规道德框架
- 情绪波动常被压缩，被部分读者形容为"情感淡漠、假人感""几乎不被情绪驱动"

**杀伐果断的表现：**
```
不留余地，斩草除根！
既然动手，便永绝后患！
此人威胁太大，今日必杀之！
```

### 4. 善于布局+幕后黑手型

**核心特征：**
- 中后期常以"幕后大佬""老爷爷型导师"身份出现
- 通过代理人或组织施加影响
- 享受"掌控局势"的爽感
- 常有多重马甲，隐藏真实实力
- 为达目的可以忍耐数十年

**行为模式：**
```
1. 建立组织/收服手下 → 2. 布局谋划 → 3. 幕后操控
4. 关键时刻现身 → 5. 收割成果 → 6. 继续隐藏
```

### 5. 两界差异+风险对冲型

**核心特征：**
- 高风险修仙世界：低调发育、苟道
- 低武/异世界：高调出手、扫平一切
- 形成强烈的反差爽感
- 利用两界差异进行资源交换
- 在不同世界有不同身份和行事风格

**行为模式：**
```
修仙界：苟住发育 → 异界：重拳出击 → 资源回流 → 继续发育
```

## 配角与反派塑造

### 配角：功能化为主

**常见配角类型：**
- **信息提供者：** 店小二、向导、老江湖、消息贩子
  - 功能：提供世界观信息、任务线索、情报
  - 特点：戏份少，但信息量大

- **资源提供者：** 商人、拍卖行主、门派长老
  - 功能：提供功法、丹药、法器、材料
  - 特点：与主角利益交换，各取所需

- **战场陪衬：** 同门、临时队友、路人高手
  - 功能：衬托主角实力，提供战斗背景
  - 特点：实力不如主角，但有一定作用

- **对比工具人：** 衬托主角能力

**特点：**
- 承载特定功能，较少完整成长弧线
- 读者评价"扁平人物""工具人"（这是常见批评点）
- 但功能性强，服务主线剧情

### 反派：直接明确为主

**常见反派类型：**
- **直接对立型：** 利益冲突、体系对立
  - 特征：与主角有明确利益冲突
  - 行为：直接针对主角，手段狠辣
  - 结局：被主角反杀，成为垫脚石

- **傲慢天才型：** 出身好、天赋高、目中无人
  - 特征：出身优越，天赋出众
  - 行为：轻视主角，主动挑衅
  - 作用：提供"打脸"爽点

- **阴谋家型：** 城府深、善算计
  - 特征：城府深沉，善于算计
  - 行为：暗中布局，试图坑害主角
  - 反转：被主角识破反制

- **"掀桌"型：** 直接干掉剧情逻辑中本应重要的角色（玩梗式处理）

**特点：**
- 较少复杂的灰色地带
- 直接明确，与主角形成冲突
- 偶尔"掀桌"式处理（争议点）

## 女性角色塑造

**典型模式：**
- 有女性角色、有亲密关系、有"开车"戏份
- 但很少形成稳定、深度刻画的感情线
- 更多是"红颜知己"点缀或工具性存在
- 主角通常不主动结婚/立誓、不因为关系牺牲核心目标

**常见类型：**
- **红颜知己型：**
  - 特征：有一定实力，与主角有暧昧关系
  - 功能：点缀剧情，偶尔提供帮助
  - 深度：刻画较浅，服务于主线

- **工具人型：**
  - 特征：身份特殊（公主、圣女、大小姐）
  - 功能：提供资源、信息或任务
  - 关系：与主角有利益绑定

**读者评价：**
- "不拒绝、不负责、有点双标"
- 刻画较浅、多服务剧情或爽点

## 人物关系模式

### 1. 利益绑定关系

**交易关系：**
- 特点：明码标价，各取所需
- 对话风格：直接、务实、不谈感情
- 示例："这丹药我要了，开个价吧。"

**合作关系：**
- 特点：基于共同目标临时结盟
- 风险：随时可能因利益变化而反目
- 示例："此事若成，好处平分。"

### 2. 师徒关系

**传统师徒：**
- 师傅：传授功法，提供庇护
- 徒弟：忠心耿耿，执行命令
- 特点：有恩情，但也有算计

**利益师徒：**
- 师傅：利用徒弟达成目的
- 徒弟：借助师傅资源成长
- 特点：互相利用，各取所需

### 3. 敌对关系

**生死仇敌：**
- 特点：不死不休，见面即分生死
- 原因：杀亲之仇、夺宝之恨、理念冲突

**竞争关系：**
- 特点：良性竞争，互相促进
- 结果：亦敌亦友，惺惺相惜

## 后期性格趋同问题

**常见现象：**
- 无论开局如何，中后期主角性格高度统一
- 都走向同一种"谨慎、自利、阴晴不定"的模式
- 像"黑道复制人"，导致作品辨识度下降

**解决建议：**
- 可以在开局设定时就确定主角独特的性格特点
- 中后期保持一定的一致性但增加细节差异
- 避免所有主角都走完全相同的路线

## 性格塑造技巧

### 通过行动展现性格（而非直接描写）

**正面示例：**
```
面对强敌，主角没有硬拼，而是迅速评估形势，
寻找退路。这种选择展现了他的谨慎和理性。
```

**避免直接描写：**
```
❌ 错误：主角是一个很谨慎的人。
✅ 正确：主角每一步都小心翼翼，生怕惊动了什么。
```

### 通过对话体现身份

**高手语气：**
- 简洁、自信、不容置疑
- 例："此事，我自有分寸。"

**小人物语气：**
- 恭敬、谨慎、试探
- 例："前辈，您说的是，晚辈明白了。"

**反派语气：**
- 傲慢、威胁、阴狠
- 例："小子，你找死！"

## 人物命名参考

### 主角常用名风格
- 单名：林、苏、叶、楚、陈、方
- 双名：轩、尘、渊、寒、墨、羽
- 示例：林轩、苏尘、叶渊、楚寒

### 配角命名风格
- 功能性：按身份命名（王掌柜、李长老）
- 反派：带负面暗示（血手、鬼面、阴九）
- 女性：柔美字眼（婉儿、清雪、梦瑶）

### 称号/绰号
- 实力称号：剑圣、刀狂、拳霸
- 特征绰号：独眼龙、铁手、鬼见愁
- 组织代号：青龙、白虎、朱雀
