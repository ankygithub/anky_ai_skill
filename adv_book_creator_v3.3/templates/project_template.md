## 五、章节大纲

### 5.1 章清单（一章 = 一个文件 `chNN-*.md`）

| 章 | 文件 | 标题 | 核心内容（3-5句） | 读者收益 | 类型标签 | 前置依赖 | 信息来源 |
|----|------|------|-------------------|----------|---------|---------|---------|
| 1 | ch01-xxx.md | 第一章 xxx | | | | 无 | |

**类型标签**：[概念] [实操] [案例] [对比] [练习] [反思] [故事] [拓展]
**前置依赖**：本节依赖哪些先完成的章节（无则填"无"），并发写作时据此定顺序
**信息来源**：直接写结论摘要 / 出处（如"XX 官方文档 2025 版"），不要只写文件路径（保证本文件自包含）
**默认不搜**：只有"不可编造的具体事实"（真实数字 / 事件 / 最新版本号 / 官方配置值 / 真实评测数据）才由写作 Agent 现场搜一次、**直接写进正文并加脚注标源**（判据见 SKILL.md §3.1；已登记进"四、数据速查"的优先复用）

### 5.2 写作与审阅分组（Part 映射）

> 把**内容强相关**的章归为一组（Part）；不相关的按 3–4 章一组。规划阶段定好——**写作按 Part 派发子 Agent、审查按 Part 串行分段**。
> **规则**：每个章**恰属一个** Part（不重不漏）；构建门禁会机械校验覆盖性（遗漏/重复/越界都会拦构建）。
> 「包含章节」列支持 `ch01, ch02` 或 `ch01–ch03`（范围）。

| Part | 包含章节 | 分组理由 |
|------|---------|---------|
| 1 | ch01, ch02, ch03 | 强相关：同属「XXX」主题 |
