# 模板：主文档素材库索引（产出 `docs/refs/README.md`）

> 使用说明：`docs/refs/README.md`。概设 / 详设阶段**主动调研**拉取的外部参考件（可复用代码 / 算法 / 配置片段 / 截图）统一放 `docs/refs/`，本文件是**唯一索引**——调研时随手登记，别只把文件丢进目录。
>
> **目录名用 `refs` 不用 `assets`**：`assets` 是 Typora 等 Markdown 编辑器给图片附件用的默认目录名，混在一起会互相干扰。
>
> 追加轮次的素材放 `docs/changes/round-NN/refs/`，索引写在该轮 `discuss.md` §4，**不并入本文件**。
>
> **红线**：文档里只写一句"参考某项目"不算数——执行 AI 找不到原件，只能凭想象实现。凡写进 2-概要设计 §12 调研记录或 3-详细设计 §1.5 硬门槛（非平凡算法）的素材，必须在此登记并可查。
