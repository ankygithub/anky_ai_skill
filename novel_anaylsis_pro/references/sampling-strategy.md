## 1. 抽样策略概述

### 1.1 为什么需要抽样？

网络小说通常规模庞大（100万-1000万字），全量分析既不可能也无必要。科学抽样的目标是：

| 目标 | 说明 |
|------|------|
| **代表性** | 样本能准确反映整体特征 |
| **效率性** | 用最少样本获取最多信息 |
| **可比性** | 不同书籍的样本可相互比较 |
| **可重复性**：抽样过程可复现 |

### 1.2 四类抽样策略总览

```
┌─────────────────────────────────────────────────────┐
│                   抽样策略体系                       │
├─────────────┬─────────────┬─────────────┬───────────┤
│  策略A      │  策略B      │  策略C      │  策略D     │
│  结构化抽样  │  重点抽样   │  随机分层   │  滑窗抽样  │
├─────────────┼─────────────┼─────────────┼───────────┤
│ 适用: 全貌  │ 适用: 核心  │ 适用: 验证  │ 适用: 追踪 │
│ 把握        │ 特征捕获    │ 代表性      │ 变化趋势   │
│             │            │             │           │
│ 样本: ~15%  │ 样本: ~8%   │ 样本: ~5%   │ 样本: ~12% │
│ 侧重: 全面  │ 侧重: 精准  │ 侧重: 公平  │ 侧重: 连续 │
└─────────────┴─────────────┴─────────────┴───────────┘
```

### 1.3 抽样策略选择指南

| 分析目标 | 推荐策略 | 组合方案 |
|---------|---------|---------|
| 首次分析/全貌了解 | A (结构化) | 单独使用 |
| 深度分析/核心特征 | B (重点) | A+B |
| 验证假设/统计检验 | C (随机分层) | A+C |
| 追踪变化/趋势分析 | D (滑窗) | A+D 或 B+D |
| 完整专业分析 | 全部 | A+B+C+D |

## 2. 四类抽样算法详解

### 2.1 策略A：结构化抽样 (Structured Sampling)

#### 算法原理
按照书籍的**固有结构**进行系统性抽样，确保每个结构单元都有代表性。

#### 抽样规则

```
输入: 总章节数 N, 书籍元信息（卷数/每卷章节数）

Step 1: 卷级抽样
  - 如果 ≤ 5 卷: 全部抽取
  - 如果 > 5 卷: 抽取首卷 + 尾卷 + 中间均匀取 3 卷
  
Step 2: 卷内章级抽样
  - 对每个选中的卷:
    - 抽取: 第1章 + 最后1章
    - 按 20% 密度均匀抽取中间章节
    - 至少保证每卷抽取 ≥ 3 章
    
Step 3: 补充抽样
  - 如果初步抽样 < 总章节的 12%:
    - 在未抽样的区域按 15% 密度补充
  - 直到达到目标样本量（约 15%）

输出: 章节索引列表 + 抽样理由标注
```

#### 参数配置

| 参数 | 默认值 | 可调范围 | 说明 |
|------|--------|---------|------|
| 卷内抽样密度 | 20% | 15%-30% | 平衡代表性和效率 |
| 最小每卷样本 | 3章 | 2-5章 | 保证每卷都有声音 |
| 总体目标比例 | 15% | 12%-20% | 根据书籍大小调整 |
| 首尾强制抽取 | 是 | 是/否 | 保留开头结尾 |

#### 示例

```
书籍: 300章, 分为10卷 (每卷30章)

卷级抽样: 第1卷, 第5卷, 第10卷 (首+中+尾)

第1卷 (30章):
  - 强制: Ch1, Ch30
  - 20%抽样: Ch6, Ch12, Ch18, Ch24
  - 小计: 6章

第5卷 (30章):
  - 强制: Ch121, Ch150
  - 20%抽样: Ch126, Ch132, Ch138, Ch144
  - 小计: 6章

第10卷 (30章):
  - 强制: Ch271, Ch300
  - 20%抽样: Ch276, Ch282, Ch288, Ch294
  - 小计: 6章

初步总计: 18章 (6%)
不足15%目标 → 补充抽样至 45章 (15%)

最终样本: 45章，覆盖全部10卷
```

#### 优点与局限

| 优点 | 局限 |
|------|------|
| 保证结构性覆盖 | 可能遗漏局部变异 |
| 可重复性强 | 对异常章节不敏感 |
| 适合初次全貌分析 | 抽样密度固定，不够灵活 |

### 2.2 策略B：重点抽样 (Focused Sampling)

#### 算法原理
针对**已知的关键节点**进行高密度抽样，确保核心特征不被遗漏。

#### 抽样规则

```
输入: 策略A的样本 + 关键节点识别结果

Step 1: 关键节点识别（基于启发式规则）
  - 高潮候选: 章节标题含关键词（决战/大战/终极/巅峰...）
  - 转折候选: 章节长度异常（>均值+2σ 或 <均值-2σ）
  - 对话密集候选: 对话占比 > 40%
  - 抒情候选: 段落平均长度 > 均值+1.5σ
  - 用户标记: 如有读者评论/笔记的高亮章节

Step 2: 重点区域扩展
  - 对每个识别的关键节点:
    - 抽取节点本身
    - 抽取前后各 1-2 章（上下文）
    - 形成"重点簇"

Step 3: 去重合并
  - 与策略A的样本合并
  - 去除重复
  - 最终样本量控制在 ~8%（相对于全书）

输出: 重点章节列表 + 节点类型标签 + 聚簇信息
```

#### 关键节点类型权重

| 节点类型 | 权重 | 抽取半径 | 说明 |
|---------|------|---------|------|
| 大高潮 | 1.0 | ±2章 | 全书最高潮 |
| 小高潮 | 0.8 | ±1章 | 卷级高潮 |
| 重要转折 | 0.7 | ±1章 | 剧情重大变化 |
| 情感高峰 | 0.6 | ±1章 | 强烈情感场景 |
| 设定揭示 | 0.5 | ±0章 | 世界观重要信息 |
| 异常章节 | 0.4 | ±0章 | 统计异常值 |

#### 示例

```
基于策略A的45章样本，进行重点抽样:

识别的关键节点:
1. Ch150 "最终决战" [大高潮] → 抽取 Ch148-152 (5章)
2. Ch89 "真相揭露" [重要转折] → 抽取 Ch88-90 (3章)
3. Ch201 "她的眼泪" [情感高峰] → 抽取 Ch200-202 (3章)
4. Ch45 (长度异常: 12000字) [异常章节] → 抽取 Ch45 (1章)
5. Ch233 "新境界开启" [设定揭示] → 抽取 Ch233 (1章)

去重后新增: 11章 (其中3章与策略A重复)
净增: 8章

策略B最终样本: 53章 (原45 + 新增8), 约17.7%
```

#### 优点与局限

| 优点 | 局限 |
|------|------|
| 捕捉核心特征精准 | 依赖节点识别的准确性 |
| 适合深度分析 | 可能过度聚焦而忽视常态 |
| 效率高（小样本大信息） | 节点识别规则需要调优 |

### 2.3 策略C：随机分层抽样 (Stratified Random Sampling)

#### 算法原理
在**确保分层代表性的前提下**引入随机性，用于统计验证和偏差检测。

#### 抽样规则

```
输入: 全书章节 + 分层方案

Step 1: 定义分层变量
  方案A - 按位置分层:
    - 前10% (开篇期)
    - 前10%-40% (发展期)
    - 40%-70% (中期)
    - 70%-90% (后期)
    - 后10% (收尾期)
  
  方案B - 按长度分层:
    - 短章 (< 均值-0.5σ)
    - 标准章 (均值±0.5σ)
    - 长章 (> 均值+0.5σ)
  
  方案C - 按功能分层 (如果已有预分析):
    - 冲突推进章
    - 人物互动章
    - 设定揭示章
    - 情绪缓冲章

Step 2: 确定各层样本量
  - 按比例分配 (Proportional): 样本量 ∝ 层大小
  - 或最优分配 (Optimal): 样本量 ∝ 层大小 × 层内方差

Step 3: 各层内随机抽取
  - 使用确定性随机种子 (seed=42)
  - 确保可重复性

Step 4: 有效性检验
  - 计算样本均值 vs 总体均值的差异
  - 如果差异 > 5%, 重新抽样或增加样本量

输出: 随机样本 + 分层信息 + 统计检验结果
```

#### 分层方案选择指南

| 分析目标 | 推荐分层方案 | 理由 |
|---------|-------------|------|
| 检验位置偏差 | 方案A (位置) | 开头/结尾/中间可能有系统性差异 |
| 检验长度偏差 | 方案B (长度) | 长短章的内容类型可能不同 |
| 检验功能偏差 | 方案C (功能) | 需要先有预分析才能分层 |
| 通用验证 | 方案A+B 组合 | 更全面 |

#### 统计检验公式

```python
# 代表性检验伪代码
def test_representativeness(sample, population, feature):
    sample_mean = mean(sample[feature])
    pop_mean = mean(population[feature])
    
    # 相对误差
    relative_error = abs(sample_mean - pop_mean) / pop_mean
    
    # 置信区间 (95%)
    ci = confidence_interval(sample[feature], alpha=0.05)
    
    # 判断
    if relative_error < 0.05 and pop_mean in ci:
        return "PASS: 样本具有代表性"
    else:
        return "WARN: 样本可能存在偏差"
```

#### 优点与局限

| 优点 | 局限 |
|------|------|
| 统计上可证明代表性 | 随机性可能遗漏重要章节 |
| 适合假设检验 | 需要预定义分层变量 |
| 可检测系统性偏差 | 样本量计算较复杂 |

### 2.4 策略D：滑窗抽样 (Sliding Window Sampling)

#### 算法原理
使用**滑动窗口**技术在时间/章节轴上进行连续采样，用于追踪特征的变化趋势。

#### 抽样规则

```
输入: 全书章节序列

Step 1: 定义窗口参数
  - 窗口大小 (window_size): 默认 10 章
  - 步长 (step_size): 默认 5 章 (50% 重叠)
  - 或使用固定数量的窗口 (如 20 个均匀分布的窗口)

Step 2: 滑动采样
  for i in range(0, N - window_size, step_size):
      window = chapters[i : i + window_size]
      
      # 窗口内抽样策略 (二选一):
      # 选项1: 窗口内全部抽取 (适用于小窗口)
      # 选项2: 窗口内按 30% 密度随机抽取 (适用于大窗口)
      
      samples.extend(window_samples)

Step 3: 时间戳标注
  - 为每个样本记录其所属窗口的位置
  - 计算窗口的中心点 (用于趋势绘图)

Step 4: 趋势分析准备
  - 数据已准备好进行时间序列分析
  - 可计算移动平均、变化率等

输出: 滑窗样本 + 时间位置信息 + 窗口编号
```

#### 窗口参数调优

| 参数 | 影响 | 调优建议 |
|------|------|---------|
| 窗口大小 | 时间分辨率 vs 平滑度 | 小窗口=高分辨率但噪声大；大窗口=平滑但模糊细节 |
| 步长 | 采样密度 vs 效率 | 步长=窗口大小(无重叠)；步长=窗口/2(50%重叠)；步长=窗口/4(75%重叠) |
| 窗口数量 | 总样本量 | 通常 15-25 个窗口即可覆盖全书 |

#### 趋势可视化模板

```
特征强度
   ↑
10 |    ╱╲    ╱╲
 8 |   ╱  ╲  ╱  ╲
 6 |  ╱    ╲╱    ╲___
 4 | ╱
 2 |╱
 0 +────────────────→ 章节(窗口中心)
    W1  W5  W10 W15 W20
```

#### 优点与局限

| 优点 | 局限 |
|------|------|
| 捕捉动态变化趋势 | 样本量大（重叠导致） |
| 适合追踪演化 | 窗口参数敏感 |
| 可视化友好 | 不适合静态特征分析 |

## 3. 打分公式与权重系统

### 3.1 综合打分公式

对于需要给出总体评分的分析项，使用以下加权公式：

$$S_{total} = \sum_{i=1}^{n} w_i \times s_i$$

其中：
- $S_{total}$: 总分 (1-10)
- $w_i$: 第i个维度的权重 ($\sum w_i = 1$)
- $s_i$: 第i个维度的得分 (1-10)

### 3.2 各层默认权重配置

#### Layer 01 (工程层) 权重

| 维度 | 权重 | 理由 |
|------|------|------|
| 章节长度合理性 | 20% | 基础结构 |
| 标题风格一致性 | 15% | 品牌识别 |
| 卷结构逻辑性 | 20% | 组织架构 |
| 功能分布均衡性 | 20% | 节奏控制 |
| 开篇吸引力 | 15% | 第一印象 |
| 结尾钩子效果 | 10% | 续读动力 |

#### Layer 03 (主角层) 权重 ⭐核心

| 维度 | 权重 | 理由 |
|------|------|------|
| 九维一致性 | 25% | 最重要：人物不能崩 |
| 决策合理性 | 20% | 行为逻辑 |
| 底线清晰度 | 15% | 道德锚点 |
| 情感真实度 | 20% | 共情基础 |
| 成长轨迹 | 20% | 动态魅力 |

#### Layer 06 (语言层) 权重 ⭐核心

| 维度 | 权重 | 理由 |
|------|------|------|
| 句式节奏 | 25% | 可读性基础 |
| 词汇丰富度 | 20% | 表达能力 |
| 对话自然度 | 20% | 人物声音 |
| 修辞恰当性 | 20% | 文学品质 |
| 风格一致性 | 15% | 指纹稳定性 |

#### 文学维度权重

| 维度 | 权重分配依据 |
|------|------------|
| 情绪波形 | 压抑质感25% + 释放质量25% + 余韵处理25% + 案例深度25% |
| 氛围配方 | 镜头20% + 色调20% + 声音20% + 配方完整性20% + 独特性20% |
| 人味指数 | 见前文四维权重（烟火25%/关系25%/脆弱25%/对话15%/生命10%） |
| 悲悼美学 | 死亡重量20% + 悲剧类型20% + 丧失谱20% + 情绪残留20% + 升华20% |
| 节奏呼吸 | 微节奏40% + 宏节奏35% + 时间流速25% |
| 作者签名 | 五要素均权（各20%） |

### 3.3 稳定度打分细则

稳定度是衡量特征在全书中一致性的关键指标：

| 分数 | 含义 | 判定标准 |
|------|------|---------|
| 9-10 | 高度稳定 | >90%的场景遵循此特征，<5%的例外且有合理解释 |
| 7-8 | 较稳定 | 75-90%遵循，例外可控 |
| 5-6 | 中等稳定 | 50-75%遵循，有明显波动 |
| 3-4 | 较不稳定 | 25-50%遵循，模式不明显 |
| 1-2 | 不稳定 | <25%遵循，可能是偶然现象 |

## 4. 参数调优建议

### 4.1 书籍规模适配

| 总章节数 | 策略A样本量 | 策略B样本量 | 窗口大小 | 备注 |
|---------|------------|------------|---------|------|
| < 50章 | 10-12章 (20-24%) | 6-8章 (12-16%) | 5章 | 小书可提高比例 |
| 50-100章 | 10-15章 (10-15%) | 8-10章 (8-10%) | 8章 | 标准配置 |
| 100-300章 | 15-45章 (5-15%) | 10-24章 (3-8%) | 10章 | 最常见范围 |
| 300-500章 | 30-60章 (6-12%) | 20-40章 (4-8%) | 15章 | 大书适当增大窗口 |
| 500-1000章 | 50-100章 (5-10%) | 40-80章 (4-8%) | 20章 | 超大书 |
| > 1000章 | 100-150章 (5-10%+) | 80-120章 (5-12%) | 25章 | 巨著，考虑分卷分析 |

### 4.2 类型适配

| 书籍类型 | 推荐调整 | 理由 |
|---------|---------|------|
| 传统文学 | 增加策略C（随机分层）权重 | 需要统计严谨性 |
| 网文/轻小说 | 增加策略B（重点）权重 | 核心爽点是关键 |
| 系列作品 | 增加策略D（滑窗）权重 | 需要追踪变化 |
| 短篇集 | 降低抽样密度，增加覆盖面 | 每篇都需要关注 |
| 同人作品 | 增加策略B中对"原作相关章节"的权重 | 这些章节往往最重要 |

### 4.3 分析目标适配

| 分析目标 | 参数调整 |
|---------|---------|
| 快速扫描 | 仅策略A，降低密度至10%，跳过文学维度 |
| 标准分析 | 策略A+B，默认参数 |
| 深度研究 | 全部策略，提高密度至20%+，增加文学维度深度 |
| 对比分析 | 两本书使用相同参数（特别是随机种子） |
| 追踪分析 | 强化策略D，减小步长以获得更高分辨率 |

## 5. 跨书对齐策略

### 5.1 为什么需要对齐？

当分析多本书并进行比较时，必须确保：
- **抽样方法一致**：不同书用不同方法会导致不可比
- **评分标准一致**：同一特征在不同书中应使用同一尺度
- **分析深度一致**：避免因投入不同而产生的偏差

### 5.2 对齐协议

#### 协议A: 固定参数对齐

```yaml
# 跨书分析的标准参数配置文件
sampling_config:
  strategy_a:
    volume_sampling_density: 0.20
    min_chapters_per_volume: 3
    overall_target_ratio: 0.15
    force_extract_first_last: true
    
  strategy_b:
    node_detection_rules: "standard_set"
    extraction_radius:
      major_climax: 2
      minor_climax: 1
      turning_point: 1
      
  strategy_c:
    stratification_method: "position_based"
    strata: 5
    random_seed: 42
    allocation_method: "proportional"
    
  strategy_d:
    window_size: 10
    step_size: 5
    overlap_ratio: 0.5
    
scoring_config:
  stability_thresholds:
    high: 0.90
    medium_high: 0.75
    medium: 0.50
    low: 0.25
    
  weight_sets:
    layer_03_protagonist: [0.25, 0.20, 0.15, 0.20, 0.20]
    layer_06_language: [0.25, 0.20, 0.20, 0.20, 0.15]
```

#### 协议B: 归一化对齐

当书籍之间规模差异巨大时：

1. **相对位置归一化**: 将绝对章号转换为百分比位置 (0%-100%)
2. **特征值归一化**: 使用 z-score 或 min-max 归一化
3. **样本量归一化**: 按总字数的固定比例抽取，而非固定章数

#### 协议C: 锚点对齐

选择共同的"锚点章节"作为对齐基准：

| 锚点类型 | 定义 | 用途 |
|---------|------|------|
| 开篇锚点 | 第1章 (或序章) | 时间零点 |
| 10%进度锚点 | 总章节×10% | 早期基线 |
| 50%进度锚点 | 中点章节 | 中期基线 |
| 90%进度锚点 | 总章节×90% | 后期基线 |
| 结尾锚点 | 最后一章 | 终点 |

### 5.3 对齐质量检验

```python
# 对齐质量检验清单
def check_alignment_quality(book_a_analysis, book_b_analysis):
    checks = []
    
    # 1. 样本量比例检验
    ratio_a = len(book_a.samples) / book_a.total_chapters
    ratio_b = len(book_b.samples) / book_b.total_chapters
    checks.append(abs(ratio_a - ratio_b) < 0.05)
    
    # 2. 位置分布检验 (KS检验)
    ks_stat, p_value = ks_test(
        book_a.sample_positions_normalized,
        book_b.sample_positions_normalized
    )
    checks.append(p_value > 0.05)  # 分布无显著差异
    
    # 3. 评分尺度一致性检验
    checks.append(check_score_calibration(
        book_a.scores, book_b.scores
    ))
    
    return all(checks)
```

## 6. 质量控制机制

### 6.1 抽样质量检核表

每次抽样完成后，执行以下检核：

#### 必须通过的检核项 (MUST)

- [ ] 样本覆盖率 ≥ 目标值的 95%
- [ ] 每个卷（如果有分卷）至少有 2 个样本
- [ ] 首章和末章都被包含（除非有意排除）
- [ ] 随机抽样使用了固定种子（可重复）
- [ ] 样本总量在合理范围内（不过多也不过少）

#### 应该通过的检核项 (SHOULD)

- [ ] 各层（如使用分层抽样）的样本量与层大小成正比
- [ ] 高潮/转折等重点区域的抽样密度 ≥ 普通区域的 1.5倍
- [ ] 样本的章节长度分布与总体分布相似（相对误差 < 10%）
- [ ] 至少有一个来自全书 25%、50%、75% 位置的样本

#### 可以通过的检核项 (MAY)

- [ ] 样本中包含了至少一个"异常章节"（如有）
- [ ] 抽样过程有日志记录（便于审查）
- [ ] 样本有备份（防止丢失）

### 6.2 分析质量检核表

#### 证据质量 (Evidence Quality)

| 检核项 | 标准 | 权重 |
|--------|------|------|
| 具体性 | 每条证据包含章节号 | 必须 |
| 原文支持 | 包含原文摘录（非 paraphrase） | 必须 |
| 相关性 | 证据与分析结论明确关联 | 必须 |
| 数量充足 | 每个主要观点 ≥ 2 条证据 | 应该 |
| 多样性 | 证据来自不同章节（非集中在少数章） | 应该 |

#### 规则质量 (Rule Quality)

| 检核项 | 标准 |
|--------|------|
| 可操作性 | 规则能直接指导行动 |
| 具体性 | 包含参数/阈值/条件 |
| 条件限制 | 说明何时使用/不使用 |
| 示例支撑 | 有正面或反面案例 |

#### 稳定度判断质量 (Stability Assessment Quality)

| 检核项 | 标准 |
|--------|------|
| 有数值评分 | 1-10分，非模糊表述 |
| 有推理过程 | 说明为什么给这个分数 |
| 有变异点 | 列出不稳定的地方（如有） |
| 有一致性说明 | 如果分数低，解释原因 |

### 6.3 常见抽样偏差及纠正

| 偏差类型 | 表现 | 纠正方法 |
|---------|------|---------|
| 选择偏差 | 只抽取"好看"的章节 | 使用随机抽样作为平衡 |
| 首尾偏差 | 过度关注开头结尾 | 强制按比例分配中间部分 |
| 长度偏差 | 倾向于抽取长章（信息量大）| 分层抽样控制 |
| 近因偏差 | 对最近章节印象更深 | 按时间均匀分布 |
| 确认偏差 | 只寻找支持预设的证据 | 主动寻找反例 |

### 抽样策略速查

```
策略A 结构化抽样 (~15%)
  ├─ 按卷抽样 (首+尾+中)
  ├─ 卷内20%密度
  ├─ 保证最小样本量
  └─ 适用: 全貌把握

策略B 重点抽样 (~8%, 叠加后~18%)
  ├─ 识别关键节点 (高潮/转折/异常)
  ├─ 节点±1-2章扩展
  ├─ 去重合并
  └─ 适用: 核心特征捕获

策略C 随机分层 (~5%)
  ├─ 定义分层变量 (位置/长度/功能)
  ├─ 按比例/最优分配
  ├─ 固定种子随机
  └─ 适用: 统计验证

策略D 滑窗抽样 (~12%)
  ├─ 窗口大小: 10章 (可调)
  ├─ 步长: 5章 (50%重叠)
  ├─ 时间戳标注
  └─ 适用: 趋势追踪

完整分析 = A + B + C + D (去重后约25-30%)

打分: 加权求和 Σ(wᵢ × sᵢ), 稳定性9-10=高度一致
对齐: 固定参数 + 归一化 + 锚点
质检: MUST/SHOULD/MAY 三级检核
```
