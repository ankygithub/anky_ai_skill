## 1. 维度概览

### 1.1 为什么需要文学维度？

十层技术框架解决的是**"如何写"**的问题（技术解构），而六大文学维度解决的是**"写得怎么样"**的问题（审美评判）。

```
十层框架（技术侧）          六大文学维度（文学侧）
├─ 怎么组织章节     →       ├─ 情绪感觉如何？（波形）
├─ 情节怎么推进     →       ├─ 氛围是什么味道？（配方）
├─ 人物怎么设计     →       ├─ 有没有人味？（指数）
├─ 怎么叙述         →       ├─ 悲伤怎么处理？（美学）
├─ 语言什么风格     →       ├─ 呼吸自然吗？（节奏）
├─ 修辞怎么用       →       └─ 能认出作者吗？（签名）
├─ 场景怎么写       
├─ 主题是什么       
└─ 体验怎么样       
```

### 1.2 六维定位图

```
              感知深度（深层）
                  ↑
                  │
     【悲悼美学】    【作者签名】   ← 灵魂层面
                  │
     【情绪波形】    【节奏呼吸】   ← 体验层面
                  │
     【氛围配方】    【人味指数】   ← 表象层面
                  │
                  └──────────→ 感知广度（表层）
```

### 1.3 分析哲学差异

| 维度 | 核心问题 | 分析立场 | 输出特色 |
|------|---------|---------|---------|
| 情绪波形 | 情绪如何波动？ | 心理学家 | 波形图+质感分类 |
| 氛围配方 | 氛围如何营造？ | 导演/摄影师 | 配方表+参数 |
| 人味指数 | 有没有生命感？ | 人类学家 | 量化指数+分级 |
| 悲悼美学 | 悲伤如何升华为美？ | 美学家/哲学家 | 类型学+升华路径 |
| 节奏呼吸 | 律动是否自然？ | 音乐家/作曲家 | 乐谱式分析 |
| 作者签名 | 指纹是什么？ | 侦探/鉴识专家 | 特征提取+画像 |

## 2. 维度一：情绪波形图 (Emotion Wave)

### 2.1 理论背景

**理论基础**: 情绪不是离散的点，而是连续的波。借鉴：
- 心理学的情绪理论（Plutchik's Wheel of Emotions）
- 叙事学的情感弧线理论（Kurt Vonnegut 的故事形状）
- 音乐的波形分析（振幅/频率/相位）

**核心假设**: 优秀的叙事会创造可识别的、有美感的情绪波形。

### 2.2 分析方法

#### Step 1: 压抑类型识别
将压抑分为5种质感：
- 憋屈型（有能力不能用）
- 无力型（想反抗做不到）
- 焦虑型（未知带来的恐惧）
- 悲伤型（失去后的隐痛）
- 孤独型（人群中的寂寞）

#### Step 2: 释放方式分类
将释放分为5种模式：
- 爆发式（洪水决堤）
- 渐进式（退潮般缓慢）
- 转化式（化为力量/智慧）
- 延迟式（很久之后才涌出）
- 替代式（间接宣泄）

#### Step 3: 波形绘制
对每个典型案例绘制概念性波形图：

```
情绪强度
   ↑
10 |         ★（释放点）
 8 |        / \
 6 |       /   \
 4 |  ____/     \____
 2 | /
 0 +------------------→ 章节
```

#### Step 4: 余韵分析
释放后的"回味"处理：
- 沉寂余韵（留白）
- 回响余韵（延续）
- 转折余韵（转向）
- 悬置余韵（留给未来）

### 2.3 输出模板

```json
{
  "suppression_textures": { /* 5种压抑质感 */ },
  "release_methods": { /* 5种释放模式 */ },
  "aftertaste_patterns": { /* 4种余韵类型 */ },
  "case_studies": [ /* 3个典型案例深度剖析 */ ]
}
```

### 2.4 与十层框架的映射

**主要映射**: Layer 10 (读者体验层)
- 情绪波形是体验层的微观深化
- Layer 10 关注"有哪些爽点和情绪点"，本维度关注"这些情绪点的质感和形态"

**辅助映射**: 
- Layer 02 (情节) — 情节的张弛直接影响波形
- Layer 03 (主角) — 主角的情感特质决定波形基调

## 3. 维度二：氛围配方 (Atmosphere)

### 3.1 理论背景

**理论基础**: 
- 电影的氛围营造理论（用光/构图/声音/调色）
- 环境心理学的空间氛围研究
- 文学的通感理论（Synesthesia in Literature）

**核心假设**: 即使是文字媒介，也可以通过精确的技术手段创造出如同电影般的"氛围"。

### 3.2 分析方法

#### 五维氛围分析模型

```
        ┌─────────────────┐
        │   1. 镜头调度    │  ← 视角/距离/运动/角度
        ├─────────────────┤
        │   2. 画面色调    │  ← 色彩/光影/构图
        ├─────────────────┤
        │   3. 声音设计    │  ← 层次/类型/功能
        ├─────────────────┤
        │   4. 嗅觉/触觉   │  ← （如有）气味/温度/质地
        ├─────────────────┤
        │   5. 词语/句式   │  ← 高频词/标志句式
        └─────────────────┘
                   ↓
            【氛围配方】
         （可复用的参数集合）
```

#### 配方提取流程

1. 识别本书最擅长的5种氛围类型
2. 对每种氛围进行五维分解
3. 提取各维度的参数值
4. 记录典型例段作为参照
5. 评估配方的独特性和可复制性

### 3.3 输出模板

```json
{
  "cinematography_and_atmosphere": { /* 镜头调度分析 */ },
  "visual_color_palette": { /* 画面色调分析 */ },
  "sound_design": { /* 声音设计分析 */ },
  "core_atmosphere_recipes": [ /* 5个完整配方 */ ],
  "atmosphere_transition_art": { /* 氛围转换艺术 */ }
}
```

### 3.4 与十层框架的映射

**主要映射**: Layer 08 (场景类型层) + Layer 05 (叙事视角层)
- 场景是氛围的载体
- 叙事镜头是氛围的工具

**独特贡献**: 提供了比 Layer 08 更细粒度的"微氛围"分析

## 4. 维度三：人味指数 (Humanity Quotient)

### 4.1 理论背景

**理论基础**:
- 存在主义哲学的人本关怀
- 文学现实主义的人物塑造理论
- AI/机器文本 vs 人类文本的可区分性研究

**核心假设**: 真正的好作品有一种"人的味道"——那是生命经验的沉淀，是无法被算法模拟的质感。

### 4.2 分析方法

#### 四大人味检测维度

| 维度 | 检测内容 | 权重 |
|------|---------|------|
| 烟火气 | 日常生活细节丰富度 | 25% |
| 关系温度 | 人际关系的温暖度 | 25% |
| 脆弱时刻 | 展示脆弱的能力和质量 | 25% |
| 非功能性对话 | "废话"的比例和质量 | 15% |
| 整体生命感 | 综合直觉判断 | 10% |

#### 评分等级

- **9-10分**: 极具人味，仿佛真人真事
- **7-8分**: 明显人味，角色鲜活
- **5-6分**: 一定人味，偏功能性
- **3-4分**: 人味稀薄，符号化
- **1-2分**: 几乎无人味，机械感

### 4.3 输出模板

```json
{
  "lifes_vapor_index": { /* 烟火气分析 */ },
  "relationship_temperature_index": { /* 关系温度分析 */ },
  "vulnerability_moments_index": { /* 脆弱时刻分析 */ },
  "non_functional_dialogue_ratio": { /* 非功能性对话分析 */ },
  "humanity_composite_index": { /* 综合评定 */ }
}
```

### 4.4 与十层框架的映射

**主要映射**: Layer 04 (人物关系层)
- Layer 04 关注人物的"功能配置"，本维度关注人物的"生命质感"

**独特贡献**: 提供了量化的人味测量工具

## 5. 维度四：悲悼美学 (Mourning Aesthetics)

### 5.1 理论背景

**理论基础**:
- 悲剧美学（Aristotle 的《诗学》到现代悲剧理论）
- 哀悼心理学（Freud 的《哀悼与忧郁》到 Kübler-Ross 模型）
- 死亡文学研究（Death Studies in Literature）

**核心假设**: 如何处理死亡和丧失，是检验作品人文深度的试金石。伟大的作品不会回避悲伤，而是将其升华为美。

### 5.2 分析方法

#### 四大分析模块

1. **死亡重量**: 死亡的呈现等级（0-5级）× 情感重量因素
2. **五种悲剧类型**: 宿命/性格/社会/伦理/存在主义
3. **丧失谱系**: 超越死亡的各类丧失（关系/能力/理想/时间等）
4. **情绪残留**: 悲伤的持久性、变形、内疚、创伤后成长

#### 悲悼美学升华路径

```
原始悲伤
    ↓
[承认] → 不回避、不淡化
    ↓
[深化] → 探索悲伤的各个层面
    ↓
[转化] → 悲伤变为力量/智慧/温柔/艺术
    ↓
[升华] → 悲伤成为美（最美的悲伤场景）
    ↓
[希望] → 在悲伤中保留一丝光亮
```

### 5.3 输出模板

```json
{
  "death_weight": { /* 死亡重量分析 */ },
  "five_tragedy_types": { /* 五种悲剧类型 */ },
  "loss_spectrum": { /* 丧失谱系 */ },
  "emotional_residue": { /* 情绪残留 */ },
  "mourning_aesthetic_sublimation": { /* 美学升华 */ }
}
```

### 5.4 与十层框架的映射

**主要映射**: Layer 09 (主题母题层) + Layer 03 (主角层)
- 悲悼是深刻的主题
- 主角面对丧失的方式反映其伦理哲学

**独特贡献**: 提供了系统化的死亡/丧失/悲伤分析框架

## 6. 维度五：节奏呼吸感 (Rhythm & Breathing)

### 6.1 理论背景

**理论基础**:
- 音乐的节奏理论（拍子/速度/强弱/休止）
- 诗歌的格律学（ meter / cadence）
- 叙事节奏研究（Narrative Pace in Fiction）

**核心假设**: 好的叙事像呼吸——有自然的吸气（积蓄）和呼气（释放），形成舒适的律动。节奏失调会让读者"窒息"。

### 6.2 分析方法

#### 双层节奏分析

**微节奏（句子-段落级别）**:
- 句长节奏（短句群/长句群/交替）
- 段落长度分布
- 对话节奏（快/慢/变速）
- 段落内部呼吸点

**宏节奏（章节-卷级别）**:
- 章节内部节奏模板
- 多章组合节奏单元
- 卷级节奏曲线
- 时间流速感知

#### 节奏诊断

| 问题 | 症状 | 检测方法 |
|------|------|---------|
| 窒息 | 长时间高强度 | 连续N章无缓冲 |
| 缺氧 | 长时间低强度 | 连续N章无高潮 |
| 心律不齐 | 快慢无规律 | 相邻章节奏突变无逻辑 |
| 停搏 | 完全失去节奏 | 整章流水账 |

### 6.3 输出模板

```json
{
  "micro_rhythm": {
    "sentence_level": { /* 句子节奏 */ },
    "paragraph_level": { /* 段落节奏 */ },
    "dialogue_rhythm": { /* 对话节奏 */ }
  },
  "macro_rhythm": {
    "chapter_internal_template": { /* 章节模板 */ },
    "multi_chapter_units": { /* 多章单元 */ },
    "volume_level_curve": { /* 卷级曲线 */ }
  },
  "time_flow_perception": { /* 时间流速 */ },
  "rhythm_diagnosis": { /* 节奏诊断 */ }
}
```

### 6.4 与十层框架的映射

**主要映射**: Layer 01 (工程层) + Layer 05 (叙事层) + Layer 06 (语言层)
- 工程结构决定宏节奏容器
- 叙事镜头影响微节奏
- 语言句式是实现节奏的基本单位

**独特贡献**: 将音乐理论引入叙事分析

## 7. 维度六：作者签名 (Author Signature)

### 7.1 理论背景

**理论基础**:
- 文体学（Stylistics）的作者识别研究
- 数字人文的作者归属（Authorship Attribution）
- 文学批评的"作者在场"理论（Barthes/Foucault 的辩论之后的新理解）

**核心假设**: 每个成熟的作者都有独特的"签名"——一组反复出现的、高度个人化的写作习惯。这些签名是无意识的暴露，比有意识的风格更稳定、更真实。

### 7.2 分析方法

#### 五大签名要素

1. **眼神写法**: 如何描写眼睛和眼神（最暴露作者审美的地方之一）
2. **固定意象系统**: 反复出现的核心意象及其个人化改造
3. **克制-爆发辩证法**: 在哪里忍住、在哪里爆发
4. **空间修辞**: 对空间的偏好和处理方式
5. **诗词基因**: 受到的诗词影响及自创的诗性时刻

#### 签名唯一性评估

```
指纹要素清单:
□ 眼神写法的独特性 (高/中/低)
□ 固定意象系统的独特性 (高/中/低)
□ 克制-爆发模式的独特性 (高/中/低)
□ 空间修辞的独特性 (高/中/低)
□ 诗词基因的独特性 (高/中/低)

综合唯一性评分: __/10
```

### 7.3 输出模板

```json
{
  "the_gaze_signature": { /* 眼神写法 */ },
  "recurring_motif_system": { /* 固定意象 */ },
  "restraint_eruption_dialectics": { /* 克制-爆发 */ },
  "spatial_rhetoric": { /* 空间修辞 */ },
  "poetic_dna": { /* 诗词基因 */ },
  "signature_composite_portrait": { /* 综合画像 */ }
}
```

### 7.4 与十层框架的映射

**主要映射**: Layer 06 (语言风格层) + Layer 07 (修辞文化层)
- 签名是语言和修辞的个人化结晶
- 是所有技术特征的"个人印记"

**独特贡献**: 提供了作者级别的身份识别

### 8.1 完整映射表

| 文学维度 | 主要映射层 | 辅助映射层 | 关系类型 |
|---------|-----------|-----------|---------|
| 情绪波形 | L10 体验 | L02 情节, L03 主角 | 微观深化 |

| 作者签名 | L06 语言, L07 修辞 | 全部层 | 个人化提炼 |

### 8.2 使用策略

**策略A: 先技术后文学**
1. 完成十层技术分析（建立客观基础）
2. 再进行六维文学分析（加入主观审美）
3. 优势：有据可依，结论扎实

**策略B: 同步进行**
1. 技术层和文学层对应分析
2. 相互印证和补充
3. 优势：保持新鲜感，发现意外联系

**策略C: 文学先行**
1. 先进行文学感知（捕捉第一印象）
2. 再用技术分析验证和细化
3. 优势：不会错过直觉性的发现

**推荐**: 策略A（最稳健）

## 9. 使用建议

### 9.1 何时使用六维文学分析？

**强烈推荐使用的场景**:
- 分析文学作品（非类型化/有文学追求的作品）
- 需要深入理解"为什么这部作品打动人"
- 进行高水平的仿写学习（不只是模仿套路）
- 评估作品的艺术价值和独特性

**可选使用的场景**:
- 分析商业类型作品（可能某些维度不适用）
- 快速扫描式分析（时间有限时）
- 初学者的练习（可以先从十层框架开始）

**不建议使用的场景**:
- 纯技术性的代码/文档分析
- 完全没有文学性的快餐读物
- 时间极度有限的场合

### 9.2 常见误区

| 误区 | 正解 |
|------|------|
| 文学分析 = 主观臆断 | 文学分析也有其方法论和证据要求 |
| 六维比十层更重要 | 两者互补，缺一不可 |
| 所有作品都需要六维分析 | 根据作品类型和分析目的灵活选择 |
| 分数越高越好 | 分数是描述性工具，不是价值判断 |
| 可以脱离十层单独使用 | 虽然可以，但结合使用效果最佳 |

### 9.3 进阶技巧

1. **跨维度关联**: 寻找六个维度之间的内在联系（如：悲悼美学影响情绪波形）
2. **动态追踪**: 如果分析系列作品，追踪签名和风格的演变
3. **比较分析**: 同时分析两部作品，进行六维对比
4. **创造性误读**: 允许有个人的解读，但要标注为"主观推断"
