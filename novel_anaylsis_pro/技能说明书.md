# novel_anaylsis_pro 技能说明书

## 一、技能概述

| 项目 | 内容 |
|------|------|
| **技能名称** | novel_anaylsis_pro |
| **核心功能** | 网文作者风格解析 |
| **定位** | 分析型技能 —— 读取作者txt作品集，生成结构化风格指纹报告 |
| **技术栈** | Python 3.13 + click + rich + jieba + openai + chardet + pytest |
| **测试覆盖** | 182 个测试用例，全部通过 |

## 二、核心能力

### 2.1 五阶段分析流水线

```
文本预处理 → 统计层分析 → LLM深读 → 交叉验证 → 报告生成
```

| 阶段 | 模块 | 说明 | 成本 |
|------|------|------|------|
| 1. 文本预处理 | `text_preprocessor.py` | 编码检测、广告清洗、章节切分 | 0 token |
| 2. 统计层 | `stat_analyzer.py` | 句长/词频/对话比/标点/四字格密度 | 0 token |
| 3. 分层抽样 | `sampler.py` | 四类切片：开篇/高潮/日常/收尾 | 0 token |
| 4. LLM深读 | `llm_analyzer.py` | 十层技术+六维文学感知分析 | 高 |
| 5. 交叉验证 | `cross_validator.py` | 多书对比，标注稳定度(H/M/L) | 0 token |
| 6. 报告生成 | `report_generator.py` | 生成5份产物 | 0 token |

### 2.2 双视角分析架构

- **技术视角**：可量化指标 + 操作规则（给AI的"操作手册"）
- **文学视角**：氛围画像 + 情绪纹理 + 美学定位（给AI的"审美指南"）

### 2.3 十层技术框架

作品工程层、情节结构层、主角伦理层、人物关系层、叙事视角层、语言风格层、修辞文化层、场景类型层、主题母题层、读者体验层

### 2.4 六维文学感知

情绪波形图、氛围配方集、人味指数、悲悼美学、节奏呼吸感、作者签名

## 三、输出产物

|------|--------|------|

## 五、使用方式

```bash
# 基础用法
python scripts/analyze.py --input-dir "D:/path/to/author_books" --output-dir "./output"

# 完整用法
python scripts/analyze.py --input-dir "D:/path/to/author_books" --model gpt-4o --intensity high

# 仅统计层（不调用LLM）
python scripts/analyze.py --input-dir "D:/path/to/author_books" --stat-only
```

## 六、关键设计亮点

1. **分层抽样策略**：从百万字压缩到~5万字，降低LLM调用成本
2. **双视角融合**：每个特征同时产出技术描述和文学描述
3. **稳定度标注**：HIGH(≥3本)/MEDIUM(2本)/LOW(1本)
4. **182个单元测试**：覆盖所有核心模块
5. **Rich终端输出**：美观的进度条和表格展示

## 七、依赖关系

- 前置技能：无（独立分析技能）
- 后置技能：novel_vela_pro / novel_vela_v3（分析结果可用于创作时的风格参考）
