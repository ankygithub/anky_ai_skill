## 第二部分：关系温度分析（Relationship Temperature Index）

### A. 关系温度测量
对书中主要人际关系进行"温度"测量：

#### 温度等级定义
- **冰点（0°C）**：敌对、仇恨、毫无感情
- **冷淡（1-20°C）**：陌生、礼貌、公事公办
- **微温（21-40°C）**：认识、有好感、但不深入
- **温暖（41-60°C）**：朋友、信任、互相关心
- **炽热（61-80°C）**：亲人/恋人、深爱、愿意牺牲
- **灼烧（81-99°C）**：激情、执念、可能有害的强烈感情
- **沸点（100°C）**：超越常规的极致情感

#### 关系温度图谱
| 关系双方 | 初始温度 | 最高温度 | 最低温度 | 最终温度 | 温度变化轨迹 |
|---------|---------|---------|---------|---------|------------|
| 主角-A | | | | | |
| 主角-B | | | | | |
| A-B | | | | | |
| ... | | | | | |

**分析要点**：
- 哪段关系的温度变化最动人？
- 是否存在"表面冷淡实际炽热"的关系？
- 温度变化的触发事件是什么？
- 有没有"永远无法升温"的遗憾关系？

### B. 关系温度的表达方式
- **语言层面**：称呼的变化、语气的变化、话语量的变化
- **行为层面**：身体距离、触碰频率、为对方做事
- **心理层面**：想念频率、担忧程度、信任程度
- **特殊仪式**：只有两人懂的默契/习惯/玩笑
- **冲突与修复**：吵架的方式、和好的方式

**最心痛的关系降温瞬间**：[原文摘录]

### C. 群体化学反应
不止一对多的关系，而是多人在一起时的"气场"：
- **三人行动态**：A-B-C三人时，关系如何变化？
- **团队氛围**：整个团体在一起的"味道"
- **派对/聚会场景**：热闹中的孤独 or 融入的快乐
- **分离与重聚**：群体解散后的各自思念

## 第三部分：脆弱时刻分析（Vulnerability Moments Index）

### A. 脆弱性的定义
脆弱 ≠ 弱小。脆弱是指：
- 展示真实自我（包括缺点和伤口）
- 承认恐惧/无助/困惑
- 依赖他人（信任的表现）
- 失去控制（情绪/身体/局面）
- 面对死亡/失去/失败

**高人味 = 允许角色（尤其是主角）有脆弱时刻**

- 情感脆弱（哭泣/崩溃/恐惧）：__次
- 社交脆弱（被误解/孤立/拒绝）：__次

### C. 脆弱时刻的质量评估
- **真实性**：这种脆弱是否符合人物设定？

**技术侧**：提取人味度量指标、烟火气检查清单、关系温度计、脆弱时刻记录表

⭐ **特别强调**：人味指数是区分"好作品"和"伟大作品"的重要指标之一。技术完美的作品可能无人味，而有瑕疵的作品可能因极高的人味而打动人心。

每个分析项必须包含：
1. **现象描述**：客观观察到的人味特征

3. **仿写规则**：可操作的"注入人味"指导原则
4. **稳定度判断**：全书人味的一致性和质量（高/中/低）
