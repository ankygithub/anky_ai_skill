# 调研报告写作规范

## MD片段规范

### YAML Frontmatter（必填）
```markdown
---
type: chapter
title: 第一章 市场规模测算
---
```

### 标题层级
- `##` = 大章节标题
- `###` = 小节标题
- `####` = 子小节

### 基础Markdown语法
- **粗体**: `**文字**`
- *斜体*: `*文字*`
- `行内代码`: `` `代码` ``
- 表格: 标准Markdown表格
- 列表: `-` 或 `1.`
- 引用: `>`

## 组件使用规范

### 信息提示块
```markdown
:::info 标题
内容
:::
```
使用场景：补充说明、背景介绍

### 成功提示块
```markdown
:::success 标题
内容
:::
```
使用场景：正向结论、核心要点

### 警告提示块
```markdown
:::warning 标题
内容
:::
```
使用场景：风险提示、注意事项

### 危险提示块
```markdown
:::danger 标题
内容
:::
```
使用场景：严重风险、禁止事项

### 对比块
```markdown
:::compare
:::left 支持观点
- 理由1
- 理由2
:::

:::right 反对观点
- 风险1
- 风险2
:::
:::
```
使用场景：正反对比、方案选型

### 步骤块
```markdown
:::steps
1. 第一步
   详细说明...
2. 第二步
   详细说明...
:::
```
使用场景：操作流程、实施步骤

### 折叠面板
```markdown
:::details 标题
详细内容...
:::
```
使用场景：详细信息、补充资料

### 证据卡片
```markdown
:::evidence 证据卡 #001
**事实陈述**：...
**数据来源**：...
**可信度**：★★★
**时效性**：2024 Q3
**交叉验证**：...
:::
```
使用场景：关键事实的证据支撑

## 组件使用铁律

| 当你要写... | 必须使用 | 最低用量 |
|------------|---------|---------|
| 章节核心要点、关键结论 | `:::success` | 每章≥1个 |
| 安全警告、风险提示 | `:::warning` | 有风险时必须用 |
| 参考信息、数据来源 | `:::info` | 有引用时必须用 |
| 2步以上的操作步骤 | `:::steps` | 有步骤时必须用 |
| 好坏对比、方案选型 | `:::compare` | 有对比时必须用 |

## 防幻觉强制规则

1. **强制搜索验证**：所有涉及具体数据、事实的内容，必须调用WebSearch验证
2. **强制信源标注**：正文引用的所有外部事实，必须标注信源来源
3. **强制时效检查**：技术类内容必须标注时效性
4. **强制矛盾处理**：多个信源矛盾时，必须并列呈现各方观点

## 信源标注格式

```
（来源：艾瑞咨询《2024中国AI客服行业报告》，获取时间：2024-05-21）
```
