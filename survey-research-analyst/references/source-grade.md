# 信源等级规范

## 证据等级体系

| 等级 | 来源类型 | 可信度 | 用途 |
|-----|---------|--------|------|
| **A级** | 政府部门公开数据、上市公司财报、招股书、监管文件、官方统计、权威行业协会 | ★★★ | 可作为核心结论的重要依据 |
| **B级** | 知名咨询机构报告、投资机构研究、头部媒体深度报道、企业公开披露、第三方平台统计 | ★★ | 可用于辅助判断，需关注统计口径 |
| **C级** | 普通媒体报道、企业宣传资料、社交媒体信息、用户评论、非正式访谈、二手转载 | ★ | 可用于发现线索和趋势，不宜单独支撑重大结论 |
| **D级** | 无来源数据、无法核验的信息、明显营销化内容、单一主观观点 | - | 不得作为核心判断依据 |

## 推荐数据源

| 数据源类型 | 具体来源 | 数据类型 |
|-----------|---------|---------|
| 行业报告 | 艾瑞、QuestMobile、易观、IDC、Gartner | 市场规模、用户画像 |
| 财报数据 | 上市公司年报、季报、招股书 | 营收、市场份额 |
| 政策法规 | 政府官网、行业协会、监管文件 | 政策趋势、准入门槛 |
| 新闻资讯 | 科技媒体、行业媒体、头部公众号 | 动态、趋势、案例 |
| 投融资 | IT桔子、企名片、36氪、投资界 | 融资动态、估值参考 |
| 用户数据 | 应用商店、电商平台、社交媒体 | 用户反馈、需求信号 |

## 证据卡片格式

```markdown
:::evidence 证据卡 #001
**事实陈述**：2024年中国AI客服市场规模约XX亿元

**数据来源**：艾瑞咨询《2024中国AI客服行业报告》

**可信度**：★★★

**时效性**：2024 Q3

**交叉验证**：与IDC数据XX亿元基本一致（偏差<10%）

**关联子问题**：子问题1-市场规模
:::
```

## 数据冲突处理规则

当不同来源数据冲突时，必须：
1. 列出所有版本
2. 说明差异可能来自统计口径不同
3. 说明报告采用哪个口径
4. 说明为什么采用该口径
5. 说明对最终结论有什么影响
