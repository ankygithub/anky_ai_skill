# SVG图形PRO (SVG_PRO) 技能设计文档

## 目标
创建一个SVG技术图表生成技能，针对不同类型的技术图表预设布局规范，确保生成的图形层次清晰、无重叠覆盖、无溢出、文字无遮挡或换行问题。

## 参考规范
- 现有 `SVG` 技能的基础规范（viewBox、无障碍、优化、样式、嵌入方式）
- `skill-creator` 技能创建规范

## 图表类型与布局规范

### 1. 系统分层架构图
- **方向**: 纵向分层，上层靠近用户，下层靠近底层
- **间距**: 层间距 ≥ 层内最高模块高度的1.5倍；同层模块水平等间距，间距 ≥ 最宽模块宽度
- **对齐**: 同层模块顶部对齐；层标题居中
- **连线**: 跨层连线优先垂直，水平偏移 ≥ 模块间距
- **自适应**: 模块数量 > 5 时，自动分两行排列

### 2. 流程图 / 时序图
- **方向**: 从左到右或从上到下流向
- **间距**: 节点间最小间距 20px；分支节点水平对齐
- **对齐**: 判断节点（菱形）后续节点垂直对齐
- **连线**: 回环连线走右侧，弧形半径 ≥ 30px；流向线使用贝塞尔曲线
- **自适应**: 分支层级 > 3 时，自动扩展画布宽度

### 3. 类图 / ER图
- **方向**: 继承层次垂直排列，父类在上，子类在下
- **间距**: 类间水平间距 ≥ 最宽类宽度 + 20px；垂直间距 ≥ 40px
- **对齐**: 同一继承链左对齐；关联类水平对齐
- **连线**: 继承线垂直；关联线水平或垂直，标签放中点加白色遮罩
- **文字**: 属性列表自动换行，最大行宽 = 节点宽度 - 16px

### 4. 网络拓扑图 / 部署图
- **方向**: 中心辐射或分层布局
- **间距**: 中心节点与边缘节点间距 ≥ 80px；同层节点等角度分布
- **对齐**: 同类型节点颜色/形状统一
- **连线**: 多条连线汇聚时使用贝塞尔曲线分流；连线标签不重叠
- **自适应**: 节点数量 > 10 时，自动扩展画布并调整缩放

### 5. 状态机 / 有限状态图
- **方向**: 状态按生命周期横向或环形排列
- **间距**: 状态节点间最小间距 60px
- **对齐**: 初始状态左侧对齐；终止状态右侧对齐
- **连线**: 转移线弧形绕行；自环放节点上方，半径 ≥ 25px
- **标签**: 事件标签沿连线方向排列，长度 > 10字符时使用引线

### 6. 思维导图 / 树形图
- **方向**: 中心主题向外辐射
- **间距**: 子节点扇形分布，同级节点间距 ≥ 节点宽度 + 20px
- **对齐**: 同级节点对齐；深层级节点自动调整角度
- **连线**: 平滑曲线连接；避免穿越其他节点
- **自适应**: 子节点深度 > 3 时，自动扩展画布；节点数量不均衡时自动调整扇形角度

### 7. 甘特图 / 时间线图
- **方向**: 横向时间轴，纵向任务列表
- **间距**: 时间轴等分刻度；任务行高 ≥ 40px
- **对齐**: 任务条左对齐开始时间；里程碑标记居中
- **文字**: 任务名称放条形内部或左侧；时间标签放轴下方
- **自适应**: 时间跨度 > 30 天时，自动调整刻度粒度

### 8. 数据图表（饼图/环形图/柱状图）
- **方向**: 数据驱动排列
- **间距**: 图例与图表间距 ≥ 20px；数据标签间距 ≥ 10px
- **对齐**: 图例垂直或水平对齐；柱状图基线对齐
- **文字**: 标签不重叠；小比例扇区使用引线标注；图例文字长度 > 15字符时截断
- **自适应**: 数据项 > 8 时，自动调整颜色区分度或启用图例滚动

## 通用规范（继承自SVG技能）
- viewBox 必须设置，确保缩放正常
- 文字与背景色对比度 ≥ 4.5:1
- 字体大小：标题14px，正文12px，标签10px
- 画布四周保留 40px 边距
- 文字标签与图形边界保留 8px padding
- 节点高度随内容自适应，最小高度 40px
- 中文使用 XML 数字字符引用或确保 UTF-8 编码

## 提示词分类体系

### A. 布局策略类（Layout Strategy）
- 定义图表方向、层级关系、对齐方式

### B. 间距与边界类（Spacing & Boundary）
- 定义层间距、模块间距、边距、最小间距常量

### C. 文字处理类（Text Handling）
- 定义字体大小、换行策略、标签位置、对比度要求

### D. 连线与路由类（Connection Routing）
- 定义连线走向、路由策略、标签处理、曲线半径

### E. 自适应与扩展类（Adaptive）
- 定义溢出处理、自动扩展、数量阈值、响应式规则

## 使用工作流

1. **识别图表类型**: 根据用户需求判断属于哪种图表类型
2. **加载规范**: 读取对应图表类型的布局规范（references/ 下对应文件）
3. **组合提示词**: 从5个分类中提取相关提示词，组合成完整生成指令
4. **生成SVG**: 基于模板和规范生成SVG代码
5. **质量检查**: 运行 validate_svg.py 或人工检查：层次清晰、无重叠、无溢出、文字无遮挡
6. **输出交付**: 提供可离线打开的 .svg 文件

## 触发条件
- 用户要求生成技术图表、架构图、流程图、类图、拓扑图、状态机、思维导图、甘特图、数据图表
- 用户提到"画个图"、"架构图"、"系统图"、"模块图"、"流程图"、"时序图"
- 用户需要SVG格式的技术可视化图表
- 用户抱怨现有SVG生成结果有重叠、遮挡、溢出等问题

- [ ] viewBox 正确设置
- [ ] 层次清晰，无重叠覆盖

- [ ] 文字无遮挡
- [ ] 文字无异常换行
- [ ] 连线清晰，无交叉混乱
- [ ] 颜色对比度足够
- [ ] 中文显示正常
