# wenchaogong-style 技能设计文档

> 文抄公创作风格辅助 Skill —— 用于模仿"借鉴流中的爽文写手"文抄公的创作风格。

---

## 一、概述

### 1.1 技能定位

`wenchaogong-style` 是一个面向网文创作的写作风格辅助工具。它系统化地总结了知名网文作家"文抄公"的创作风格，包括快节奏爽文、强设定弱文学、极度理性+精致利己+谨慎苟道+杀伐果断+善于布局+幕后黑手等核心特征，并提供章节大纲生成、战斗场景描写、境界突破描写等辅助功能。

核心理念：**将成功的商业写作模式提炼为可复用的创作模板**。

### 1.2 核心价值

网文创作中的核心挑战：
- **节奏把控难**：爽点密度、剧情推进速度难以把握
- **主角人设不统一**：理性与感性的平衡容易失控
- **世界观设计薄弱**：力量体系不清晰、设定不完整
- **套路模板缺乏**：开局、打脸、升级等经典套路缺乏系统化整理

本技能通过文抄公的风格解构，提供一套完整的创作原则、套路库和工具集。

### 1.3 核心风格标签

| 标签 | 说明 |
|------|------|
| 快节奏爽文 | 剧情紧凑、冲突密集、爽点频繁 |
| 强设定弱文学 | 设定详细严谨，语言简洁明快 |
| 极度理性+精致利己 | 利益最大化是第一准则 |
| 谨慎苟道+杀伐果断 | 不惹事但也不怕事，该杀则杀 |
| 善于布局+幕后黑手 | 常走幕后大佬路线 |
| 缝合创新+本土化改造 | 借鉴热门元素+二次加工 |

### 1.4 适用题材

- 武侠/仙侠/玄幻
- 系统流/金手指流/苟道流/稳健流
- 无限流/诸天流/两界流
- 主角理性冷静型故事
- 快节奏爽文+设定驱动型作品

## 三、核心模块

### 3.1 核心创作原则

#### 叙事节奏：快、稳、爽

**节奏特点**：
- 开局即入戏，快速建立危机感
- 打脸与升级点密集（前中期极强）
- 主线清晰，副本推进干脆利落
- 剧情环环相扣，爽点密集不拖沓

**章节结构模板**：
```
【开头】承接上文 → 引入危机
【发展】金手指/能力 → 解决问题
【高潮】战斗/冲突/打脸
【结尾】收获 → 新危机 → 悬念钩子
```

#### 主角塑造：理性、苟道、利己

**核心人格画像**：
- **极度理性**：行事以利益最大化为核心，情感让位于生存与变强
- **谨慎苟道**：擅长隐藏实力，避免无谓消耗，伺机而动
- **杀伐果断**：对敌不做过多犹豫，能杀则杀，绝不圣母
- **善于布局**：常走幕后黑手路线，通过代理人或组织施加影响
- **目标明确**：核心目标为"超脱/长生/最高力量"
- **情绪内敛**：心理活动服务于决策逻辑，少大段独白

**行为模式**：
```
评估风险 → 计算收益 → 制定计划 → 坚决执行 → 收割成果 → 低调发育
```

#### 世界观设定：缝合+本土化

**核心技巧**：
- 借鉴热门元素（无限流/巫师流/苟道流）
- 本土化改造（气运/命格/东方修道/华夏元素）
- 二次加工形成自己的"组合拳"
- 力量体系清晰、世界观相对完整

**力量体系特点**：
- 明确的等级划分（先天/后天/宗师等）
- 数据化呈现：使用"芯片""系统""面板"量化能力
- 弱肉强食：实力为尊的丛林法则

#### 语言风格：高效信息通道

**特点**：
- 简洁明快、流畅直白
- 短句为主、信息密度高
- 白话为主、少繁复修辞
- 对话功能性强、服务剧情
- 整体情绪偏克制、少抒情独白

### 3.2 经典套路库

#### 开局套路

**穿越重生型**：
```
开局惨（被欺负/废物/将死）→ 获金手指（系统/芯片/特殊能力）→
快速提升 → 打脸挑衅者 → 定目标（超脱/长生/最高力量）
```

**本土崛起型**：
```
底层处境 → 意外机缘 → 初步提升 → 解决眼前危机 → 埋下伏笔
```

#### 打脸套路

**扮猪吃虎型**：
```
隐藏实力 → 被挑衅 → 关键爆发 → 反杀打脸 → 震惊众人
```

**越级挑战型**：
```
实力差距 → 智慧布局 → 凭借金手指 → 以弱胜强 → 创造奇迹
```

**反杀型**：
```
反派以为胜券在握 → 主角底牌尽出 → 反杀成功 → 反派震惊
```

#### 升级套路

**境界突破型**：
```
积累足够 → 寻找安全地 → 突破瓶颈 → 实力质变 → 测试新能力
```

**资源获取型**：
```
发现线索 → 准备探索 → 进入险地 → 遭遇危险 → 解决问题 → 获得宝物 → 安全撤离
```

#### 经典流程

**文抄公式经典流程（概括化）**：
```
开局弱 → 获金手指/身份 → 一路升级碾压、布局 → 换地图 → 继续碾压
→ 后期世界级高度时开小号重来 → 导致重复感（需要注意）
```

### 3.3 爽点设置指南

#### 小高潮（每 3-5 章）

| 类型 | 示例 |
|------|------|
| 实力提升 | 境界突破、学会新功法 |
| 打脸爽 | 反杀挑衅者、揭穿阴谋 |
| 收获爽 | 寻宝获得、资源获取 |
| 身份提升 | 晋升、成名 |

#### 大高潮（每 30-50 章）

| 类型 | 示例 |
|------|------|
| 境界大突破 | 跨越一个大境界 |
| 重大复仇 | 击杀宿敌 |
| 地图切换 | 进入更高级世界 |
| 身份揭露 | 隐藏身份曝光 |

### 3.4 章节大纲生成器 (generate_chapter_outline.py)

**职责**：根据当前剧情状态快速生成章节大纲。

**输入参数**：
```
当前处境：练气三层外门弟子
面临危机：内门弟子挑衅，3 日后比武
预期收获：突破练气四层，获得宗门奖励
章节类型：战斗型
```

**输出**：结构化的章节大纲，包含开头/发展/高潮/结尾四个部分。

### 3.5 战斗场景生成器 (combat_scene_generator.py)

**职责**：生成符合文抄公风格的战斗场景描写。

**输入参数**：
```
主角：林轩（练气三层）
敌人：王虎（练气五层）
地点：演武场
策略：智取（不硬拼）
结果：完胜
```

**生成原则**：
- 战斗描写简洁有力，不过度渲染
- 突出策略性（智取优先于硬拼）
- 战斗过程体现实力差距与智谋弥补
- 结尾有收获和后续铺垫

### 3.6 境界突破描写模板 (breakthrough_generator.py)

**职责**：生成符合文抄公风格的境界突破描写。

**输入参数**：
```
当前境界：练气三层
目标境界：练气四层
突破方式：资源辅助 / 战斗感悟 / 顿悟
环境：密室 / 山洞 / 战斗中
```

**突破流程模板**：
```
1. 准备阶段：收集资源、寻找安全地点
2. 突破开始：灵气汇聚、经脉运转
3. 瓶颈冲击：遇到阻力、加大力度
4. 突破成功：气息变化、实力质变
5. 测试验证：尝试新能力、确认效果
6. 后续安排：低调发育、巩固境界
```

### 3.7 写作检查清单

共 10 项检查点：

| 序号 | 检查项 | 说明 |
|------|--------|------|
| 1 | 开局是否快速建立危机感？ | 开局即入戏，不拖沓 |
| 2 | 主角行为是否符合理性利己原则？ | 利益最大化是核心准则 |
| 3 | 是否有明确的实力提升/收获？ | 每章应有获得感 |
| 4 | 战斗描写是否简洁有力？ | 不过度渲染，突出策略 |
| 5 | 章节结尾是否有悬念钩子？ | 引发阅读期待 |
| 6 | 设定呈现是否清晰不晦涩？ | 设定服务剧情，不喧宾夺主 |
| 7 | 配角是否功能化但不扁平？ | 有功能但有个性 |
| 8 | 节奏是否紧凑不拖沓？ | 剧情推进干脆利落 |
| 9 | 爽点是否密集有节奏？ | 小高潮每 3-5 章，大高潮每 30-50 章 |
| 10 | 是否存在无意义的情感描写？ | 情感服务决策逻辑 |

## 七、关键设计决策

### 7.1 风格规则优先于内容生成

**决策**：先定义风格规则，再提供内容生成工具。

**原因**：
- 风格规则是底层约束，确保所有生成内容的一致性
- 工具可以替换，但风格规则是核心竞争力
- 用户可以先学习风格规则，再使用工具辅助

### 7.2 套路库与本土化改造并重

**决策**：提供经典套路模板，同时强调本土化改造。

**原因**：
- 套路是经过市场验证的成功模式
- 但纯套路会导致重复感和读者疲劳
- 本土化改造（气运/命格/东方元素）赋予套路新鲜感
- "缝合创新"是文抄公的核心竞争力

### 7.3 去 AI 味与优缺点平衡

**决策**：明确标注文抄公风格的优缺点，提供改善建议。

**文抄公风格的优点**：
- 更新稳定、量大管饱
- 设定新颖、组合感强
- 前中期节奏爽点密度高

**文抄公风格的争议点**：
- 人物工具化、情感表达偏淡
- 文学性不高、匠气重
- 后期易平、重复感强

**改善建议**：
- 关键配角可以赋予复杂背景
- 偶尔增加情感互动但不喧宾夺主
- 后期地图切换时增加新元素、避免重复
- 控制节奏，避免过度工具化
- 缝合元素时保持逻辑自洽
- 保持冷静基调，避免浓烈抒情

### 7.4 检查清单驱动质量

**决策**：提供 10 项写作检查清单。

**原因**：
- 将抽象的风格规则转化为可执行的检查点
- 写作后逐项确认，确保质量底线
- 防止忽略关键要素（如悬念钩子、爽点密度）
- 适合 AI 和人类写作者共同使用

### 8.2 使用场景

| 场景 | 使用方式 |
|------|---------|
| 创作新章节 | 调用 generate_chapter_outline.py |
| 写战斗场景 | 调用 combat_scene_generator.py |
| 写突破场景 | 调用 breakthrough_generator.py |
| 设计新角色 | 参考 character-archetypes.md |
| 设计世界观 | 参考 worldbuilding-guide.md |
| 优化文风 | 参考 writing-patterns.md |

### 8.3 注意事项

1. **风格一致性**：一旦选择文抄公风格，全书应保持一致
2. **避免过度工具化**：配角可以功能化，但不要完全扁平
3. **注意后期节奏**：换地图时要增加新元素，避免重复感
4. **情感克制但不缺失**：可以有情感互动，但不喧宾夺主
5. **设定服务剧情**：设定要推动剧情，不要为设定而设定
6. **爽点有节奏**：不是越多越好，要有压抑和释放的交替
7. **缝合要自洽**：借鉴不同元素时要保持内部逻辑一致
