# T01 新技术学习类调研模板

## 调研维度

### D1 核心概念与术语地图
- 调研目标：明确关键术语、概念边界、常见混淆点
- 搜索关键词：
  - "[主题] 核心概念 术语 定义"
  - "[主题] key concepts terminology glossary"
  - "[主题] 常见误区 概念混淆"
- 预期输出：概念表、术语树、先修知识清单

### D2 技术演进与问题背景
- 调研目标：该技术为什么出现，解决了旧体系什么问题
- 搜索关键词：
  - "[主题] 发展历史 演进 时间线"
  - "[主题] history evolution timeline"
  - "[主题] 解决了什么问题 痛点"
- 预期输出：时间线、关键版本、技术转折点

### D3 架构原理与底层机制
- 调研目标：核心组件、运行机制、数据流、控制流
- 搜索关键词：
  - "[主题] 架构 原理 底层机制"
  - "[主题] architecture internals how it works"
  - "[主题] 源码分析 设计哲学"
- 预期输出：架构说明、关键流程、可视化图建议

### D4 生态工具与选型对比
- 调研目标：主流工具/平台/替代方案对比
- 搜索关键词：
  - "[主题] vs [竞品] 对比 选型"
  - "[主题] comparison alternatives"
  - "[主题] 最佳实践 工具链"
- 预期输出：对比表、选型决策树、适用场景

### D5 实战路径与项目案例
- 调研目标：从最小可运行到真实工程场景
- 搜索关键词：
  - "[主题] 入门教程 实战 项目"
  - "[主题] getting started tutorial project"
  - "[主题] 生产环境 实战案例"
- 预期输出：案例列表、代码需求、实验环境要求

### D6 常见错误与排障指南
- 调研目标：新手和工程实践高频问题
- 搜索关键词：
  - "[主题] 常见错误 排查 踩坑"
  - "[主题] common errors troubleshooting"
  - "[主题] FAQ 问题解决"
- 预期输出：错误现象→原因→排查步骤→修复方案

### D7 性能安全与生产实践
- 调研目标：可靠性、安全性、性能优化
- 搜索关键词：
  - "[主题] 性能优化 调优 benchmark"
  - "[主题] security best practices"
  - "[主题] 生产环境 部署 运维"
- 预期输出：最佳实践清单、风险清单

### D8 学习路线与能力模型
- 调研目标：入门→进阶路线、阶段目标、练习任务
- 搜索关键词：
  - "[主题] 学习路线 路线图 路线图"
  - "[主题] learning path roadmap"
  - "[主题] 认证 课程 书单"
- 预期输出：阶段目标、练习任务、延伸资料

### D9 行业案例与团队经验
- 调研目标：企业实践、技术大会、工程博客
- 搜索关键词：
  - "[主题] 企业实践 案例 study"
  - "[主题] conference talk engineering blog"
  - "[主题] 公司 实践 生产"
- 预期输出：案例摘要、可迁移经验

### D10 未来趋势与边界判断
- 调研目标：发展方向、局限、替代可能
- 搜索关键词：
  - "[主题] 未来趋势 发展方向 2025 2026"
  - "[主题] limitations drawbacks future"
  - "[主题] 替代方案 竞争技术"
- 预期输出：趋势判断、谨慎提示
