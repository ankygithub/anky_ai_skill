# T10 文学写作类调研模板

## 调研维度

### D1 体裁特征与范本
- 调研目标：该体裁的定义、特征、代表作、写作规范
- 搜索关键词：
  - "[体裁] 特征 定义 范本 代表作品"
  - "[genre] characteristics definition examples canon"
  - "[体裁] 写作规范 要求 经典"
- 预期输出：体裁画像、代表作品清单、写作规范

### D2 叙事结构 / 格律
- 调研目标：叙事框架、情节结构、节奏设计、诗歌格律规则
- 搜索关键词：
  - "[体裁] 叙事结构 情节设计 节奏"
  - "[genre] narrative structure plot pacing meter"
  - "[体裁] 写作结构 模板 分析"
- 预期输出：结构模板图、节奏分析方法

### D3 语言风格模仿
- 调研目标：典型语言风格特征、修辞手法、句式特点
- 搜索关键词：
  - "[作家/流派] 语言风格 修辞 句式"
  - "[author] writing style rhetoric sentence patterns"
  - "[体裁] 语言特点 模仿 练习"
- 预期输出：风格要素清单、仿写练习模板

### D4 灵感触发与素材
- 调研目标：灵感来源方法、素材收集技巧、观察训练
- 搜索关键词：
  - "写作灵感 素材收集 观察方法"
  - "writing inspiration observation material collection"
  - "作家 灵感来源 创作过程 笔记"
- 预期输出：灵感触发方法、素材库模板、观察训练

### D5 常见败笔与修改
- 调研目标：新手高频错误、诊断方法、修改策略
- 搜索关键词：
  - "写作 常见错误 败笔 修改"
  - "writing common mistakes flaws revision"
  - "[体裁] 写作避坑 审稿意见 修改"
- 预期输出：错误类型清单、修改对照示例

### D6 文论观点
- 调研目标：文学理论中对该体裁/主题的核心观点与批评视角
- 搜索关键词：
  - "[体裁/主题] 文学理论 批评 观点"
  - "[genre/theme] literary theory criticism perspective"
  - "[作家/流派] 文论 解读 学术"
- 预期输出：文论观点摘要、批评框架

### D7 角色 / 意象 / 场景塑造
- 调研目标：人物刻画、意象构建、场景营造的技巧
- 搜索关键词：
  - "人物塑造 意象 场景描写 技巧"
  - "character development imagery scene writing techniques"
  - "[体裁] 角色塑造 细节 氛围"
- 预期输出：塑造技巧清单、经典片段分析

### D8 声音与节奏
- 调研目标：文本韵律、语感训练、朗读节奏控制
- 搜索关键词：
  - "写作 节奏感 语感 韵律 朗读"
  - "writing rhythm prosody cadence reading aloud"
  - "文本声音 语气 语流 训练"
- 预期输出：节奏分析方法、语感训练方案

### D9 发表路径
- 调研目标：投稿渠道、出版社选择、投稿技巧、版权保护
- 搜索关键词：
  - "[体裁] 投稿 出版社 发表 渠道"
  - "[genre] submission publishing magazine press"
  - "文学投稿 技巧 版权保护 合同"
- 预期输出：发表路径图、投稿指南、版权注意事项
