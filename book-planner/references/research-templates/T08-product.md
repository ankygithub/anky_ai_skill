# T08 产品工具手册类调研模板

## 调研维度

### D1 官方功能与版本变化
- 调研目标：核心功能清单、版本更新记录、废弃/新增功能
- 搜索关键词：
  - "[产品] 功能介绍 版本更新 更新日志"
  - "[产品] features changelog version updates"
  - "[产品] 新版本变化 废弃功能"
- 预期输出：功能矩阵、版本演进表、迁移指南

### D2 核心使用场景
- 调研目标：该产品最适合解决的核心问题与典型场景
- 搜索关键词：
  - "[产品] 使用场景 典型用例 最佳实践"
  - "[product] use cases best practices examples"
  - "[产品] 什么场景下用 适用人群"
- 预期输出：场景分类表、用例说明

### D3 新手任务流
- 调研目标：从零开始的最小上手路径、关键步骤、常见卡点
- 搜索关键词：
  - "[产品] 新手入门 教程 第一步"
  - "[product] getting started tutorial beginner"
  - "[产品] 新手指南 上手流程 避坑"
- 预期输出：分步引导流程、新手任务清单

### D4 高级技巧
- 调研目标：进阶功能、隐藏技巧、效率提升方法
- 搜索关键词：
  - "[产品] 高级技巧 进阶用法 效率"
  - "[product] advanced tips tricks power user"
  - "[产品] 快捷键 高级功能 技巧"
- 预期输出：高级技巧清单、效率提升对照

### D5 常见错误恢复
- 调研目标：高频误操作、数据恢复方法、故障排除
- 搜索关键词：
  - "[产品] 常见错误 恢复 故障排除"
  - "[product] common errors recovery troubleshooting"
  - "[产品] 误操作 数据恢复 撤销"
- 预期输出：错误→恢复对照表、应急流程

### D6 同类工具对比迁移
- 调研目标：与竞品的功能对比、迁移路径、选择建议
- 搜索关键词：
  - "[产品] vs [竞品] 对比 差异"
  - "[product] comparison alternative migration"
  - "[产品] 竞品分析 选型 迁移"
- 预期输出：对比矩阵、迁移步骤、选择决策树

### D7 自动化扩展
- 调研目标：API、插件、自动化脚本、与其他工具的集成
- 搜索关键词：
  - "[产品] API 插件 自动化 集成"
  - "[product] API plugin automation integration"
  - "[产品] 扩展 脚本 工作流"
- 预期输出：扩展能力清单、集成方案

### D8 跨平台适配
- 调研目标：不同操作系统、设备间的差异与同步机制
- 搜索关键词：
  - "[产品] 跨平台 多端 同步 差异"
  - "[product] cross platform sync differences"
  - "[产品] Windows Mac 移动端 适配"
- 预期输出：平台对比表、同步注意事项

### D9 阶梯练习
- 调研目标：从简单到复杂的练习任务体系
- 搜索关键词：
  - "[产品] 练习 项目 实操"
  - "[product] practice exercises projects"
  - "[产品] 学习路径 任务 练习"
- 预期输出：分级练习任务、评估标准
